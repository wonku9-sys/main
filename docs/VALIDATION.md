# 검증 결과 — 2026-10-17

현재 Linux 클라우드에서 Python 3.12.14, PySide6 6.8.3, SQLite를 사용해 검증했습니다. 사진은 업무 화면 구성의 참고 자료로 사용했고 기존 프로그램의 코드나 데이터를 가져오지 않았습니다.

## 완료한 검증

- 도메인 테스트 19개: 소수 3자리 수량, 원화 반올림, 전표/재고/결제 원자성, 재고 부족과 동시 과판매 차단, 초과 정산 차단, 이동평균 원가 및 취소 제한, 권한, 비밀번호, 관리자 보호, 재실행 자료 보존, 검증된 백업.
- GUI 및 엑셀 테스트 11개: 실제 Qt 위젯으로 10개 화면 조회, 1366×768/1080×660 크기, 검색·조회 합계·숫자 정렬, 사용자별 메뉴, 실제 입력·정산·취소 대화상자, 수식으로 해석되지 않는 엑셀 문자열, 숫자 셀과 필터.
- 전체 자동 테스트 **30개 통과**, 실패·건너뜀 0개.
- `python -m seoyoung_pos --demo --smoke-test`로 12개 상품, 12개 매입전표, 7개 매출전표와 모든 업무 화면 시작 확인. 새 SQLite 연결로 저장 내역을 다시 조회했습니다.
- 실제 Qt 화면 7종을 PNG로 캡처해 배치를 확인했습니다. Linux GUI 검증에는 Qt의 offscreen 플랫폼을 사용했습니다.
- `uv sync --frozen --extra dev`로 버전·해시가 고정된 개발 환경을 구성했습니다. `bash scripts/setup_cloud.sh`로 설치 및 검증을 재현합니다.

## Windows 배포물 검증 범위

Windows x64용 Python·Qt·SQLite와 실제 `SeoyoungPOS.exe`를 함께 제공하는 포터블 ZIP을 조립했습니다. 공식 Python NuGet 배포본 SHA512, PyPI wheel SHA256, PE x64 형식과 DLL 의존 파일, ZIP 무결성을 검사합니다. 실행 파일 안의 애플리케이션 진입점은 Linux Python으로 별도 실행해 확인했습니다.

**이 클라우드에서는 Windows PE 실행이나 실제 Windows 10/11에서의 동작을 검증하지 않았습니다.** ZIP 내부 `PORTABLE-BUNDLE.json` 및 별도 `build-report.json`에 검증 범위가 기록됩니다. Windows에서의 빌드/스모크 테스트를 위한 `build_windows.bat`와 GitHub Actions도 포함했으며 원격 빌드 실행이나 게시를 수행하지 않았습니다.

Windows에서 ZIP 전체를 해제한 뒤 EXE 실행, 최초 관리자 등록, 공급사·상품 등록, 매입·매출, 추가 정산, 종료 후 자료 유지, 엑셀과 백업을 확인할 수 있습니다. 샘플 확인은 `SeoyoungPOS.exe --demo`로 실행합니다. EXE만 따로 옮기면 안 됩니다.

## 구현된 업무 범위

공급사/판매처, 상품, 매입/매출 전표, 추가 지급/수금, 미결제 잔액, 재고 입출고·조정, 일별 보고서, 엑셀, 사용자/권한/비밀번호, 감사 기록과 백업을 제공합니다. 실제 업무 DB에는 공용 계정이나 샘플 거래를 만들지 않습니다.

지급/수금된 전표의 취소와 이후 재고가 출고된 매입 취소는 제한됩니다. 원가는 거래일의 과거 전체를 재계산하지 않고 실제 등록 순서의 이동평균을 적용합니다. 전용 반품 전표, 기존 자료 자동 이관, 저울·카드 단말기·프린터 연동과 세무 신고는 포함하지 않습니다.

클라우드 설치·시작 지침 저장은 환경 게시와 별개입니다. 새 작업에 게시된 환경의 복원은 아직 검증하지 않았습니다.
