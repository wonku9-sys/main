# 서영 POS · Windows 포터블

## 1.1.0 · 설명서 기준 단독 실행 업무 확장

- 서버·인터넷·카드 연동 없이 한 대의 PC에서 SQLite로 처리합니다.
- 상단 메뉴·아이콘 바로가기·왼쪽 업무 트리와 촘촘한 조회 표로 15개 업무 화면을 구성했습니다.
- 거래처 원장에 기간별 전기이월·발생·지급/수금·기말잔액을 표시합니다.
- 여러 상품의 실제 수량을 일괄 반영하고, 오래된 장부수량으로 덮어쓰기를 차단하며 실사 이력을 보존합니다.
- 일·월·상품·분류·공급사 집계를 제공하고 서로 다른 수량 단위는 구분합니다.
- 회원 관리·수동 포인트 원장·기간 특매와 별도 사용자 권한을 추가했습니다.
- 특매 단가는 상품 선택 시 거래일을 기준으로 제시하고, 날짜 변경 후 재적용은 확인을 받습니다.

- 상품정보·매입정보·판매정보·재고정보·변경로그 탭으로 상품 창을 재구성했습니다.
- 상품 기본정보와 가격은 왼쪽, 현재고·보관정보·메모는 오른쪽에 모았습니다.
- 대·중·소분류, 영수증명, 용량·단위용량, 창고·매대, 박스입수와 키워드를 저장할 수 있습니다.
- 판매이익률을 바로 확인하고, 공급사를 검색해 선택하며, 적용 버튼으로 창을 닫지 않고 저장할 수 있습니다.
- 기존 데이터베이스에 필요한 항목을 자동으로 추가하고 기존 상품·거래·재고·계정을 보존합니다. 업데이트 전 백업을 권장합니다.

과세 구분과 보관정보는 상품 속성으로 기록되며 기존 전표의 단가·금액·재고 계산을 바꾸지 않습니다.

포인트는 매출 자동 적립·결제와 연결하지 않으며, 잔액 이력은 등록 순서 기준입니다. 설명서의 모든 기능을 제공하지 않습니다. [설명서 대응 범위](MANUAL_SCOPE.md)의 미지원 업무를 확인하세요. 전용 반품·환불, 과거 전표 직접 수정, 단위 자동 환산, 계산원·월재고 확정 마감은 미지원입니다.

PC에서 사용할 프로그램은 아래 Assets의 **SeoyoungPOS-Windows-x64-portable.zip**입니다. `SeoyoungPOS-source.zip`은 개발용 소스입니다.

1. Windows 10(1809 이상)/11 64비트 PC에 프로그램 ZIP을 다운로드합니다.
2. ZIP **전체**를 쓰기 가능한 폴더에 압축 해제합니다.
3. `SeoyoungPOS` 폴더 안의 `SeoyoungPOS.exe`를 실행합니다.
4. 최초 실행 시 관리자 아이디·이름·비밀번호를 직접 등록합니다. Python 설치는 필요하지 않습니다.

프로그램 종료 후에도 EXE 옆 `data` 폴더의 거래자료가 보존됩니다. EXE만 따로 옮기지 말고 폴더 전체를 보관하세요. 업데이트 전에는 설정의 백업 기능으로 거래자료를 보관하고 기존 `data` 폴더를 유지하세요.

로그인·사용자 권한, 공급사/판매처, 상품, 매입·매출 전표, 추가 지급/수금, 미결제 잔액, 재고 조정/이력, 엑셀 내보내기와 백업을 제공합니다. 지급/수금된 전표의 취소와 이후 재고가 출고된 매입 취소는 제한됩니다. 전용 반품 전표와 하드웨어 연동은 포함하지 않습니다.

태그 배포 작업은 Windows에서 자동 테스트와 빌드를 실행하고, 생성된 EXE의 데모 시작 검증이 성공한 뒤 이 파일을 게시합니다. 자동 검증은 실제 매장의 Windows PC에서 업무 흐름을 확인하는 과정을 대체하지 않습니다. 애플리케이션 코드 서명은 포함하지 않습니다.
