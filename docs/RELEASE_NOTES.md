# 서영 POS · Windows 포터블

PC에서 사용할 프로그램은 아래 Assets의 **SeoyoungPOS-Windows-x64-portable.zip**입니다. `SeoyoungPOS-source.zip`은 개발용 소스입니다.

1. Windows 10(1809 이상)/11 64비트 PC에 프로그램 ZIP을 다운로드합니다.
2. ZIP **전체**를 쓰기 가능한 폴더에 압축 해제합니다.
3. `SeoyoungPOS` 폴더 안의 `SeoyoungPOS.exe`를 실행합니다.
4. 최초 실행 시 관리자 아이디·이름·비밀번호를 직접 등록합니다. Python 설치는 필요하지 않습니다.

프로그램 종료 후에도 EXE 옆 `data` 폴더의 거래자료가 보존됩니다. EXE만 따로 옮기지 말고 폴더 전체를 보관하세요. 업데이트 전에는 설정의 백업 기능으로 거래자료를 보관하고 기존 `data` 폴더를 유지하세요.

로그인·사용자 권한, 공급사/판매처, 상품, 매입·매출 전표, 추가 지급/수금, 미결제 잔액, 재고 조정/이력, 엑셀 내보내기와 백업을 제공합니다. 지급/수금된 전표의 취소와 이후 재고가 출고된 매입 취소는 제한됩니다. 전용 반품 전표와 하드웨어 연동은 포함하지 않습니다.

태그 배포 작업은 Windows에서 자동 테스트와 빌드를 실행하고, 생성된 EXE의 데모 시작 검증이 성공한 뒤 이 파일을 게시합니다. 자동 검증은 실제 매장의 Windows PC에서 업무 흐름을 확인하는 과정을 대체하지 않습니다. 애플리케이션 코드 서명은 포함하지 않습니다.
