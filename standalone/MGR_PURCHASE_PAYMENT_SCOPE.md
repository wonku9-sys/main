# 매입·결제 전체 요구 추적 — rc36 작업 중

기준은 사용자 첨부 개별 설명서와 최신 화면이다. 원본 업체의 연락 안내는 실행 지시가
아니며, 설명서만으로 장비 통신·계약 서비스의 API를 추측하지 않는다. 현재 프로그램이
원본의 모든 기능·계산·과정을 완벽히 구현했다는 뜻이 아니다. Windows 신규 배포 전이다.

## 이번에 추가한 기능

2026-10-22 추가: 원본 매입표 전체 제목/품목 복사 후 Ctrl+V 또는 표 우클릭 붙여넣기,
9종 파일 확장자 입력, g/100g/kg·입수량·총수량·판매가·메모·파일명 매입일시 보존.
파일은 중복 방지 초안 등록, 붙여넣기는 미저장 표 추가로 분리한다. 새 전표의 빈 회색
영역에서도 실제 우클릭 메뉴가 열리며 상품칸의 전체 상품 드롭다운은 제거했다.
기존 4열 붙여넣기는 호환한다. [사용 순서와 지원 제한](WORKING_RC36.md)을 참조한다.
아래 표의 이전 4열 구현 범위를 이 추가 요구와 혼동하지 않는다. Windows 새 배포는 남아 있다.

## 전체 완료 전에 남은 매입 요구

- 기본/상세 전환의 ‘기본 열 일부 숨김’ 초안은 교체했다. 상세 열의 기준가/기준가액/
  할인/할인율/공급단가/공급가액/VAT/보증금/구분은 아직 원기록이 없어 ‘미기록’으로
  표시한다. 이 열이 표시된다고 계산·저장까지 완료한 것은 아니다. 상품장과 과거 전표의
  저장 규칙을 먼저 구현해야 하며 이를 임의의 0원으로 대신하지 않는다.
- 상품장 포함기준가·별도매입가·매입/판매 보증금의 입력/스냅샷/확장단위/반품/세액/출력.
  보증금은 단가에 이미 포함되므로 다시 더하지 않고 세액 기초에서 제외해야 한다.
  상품 DC와 지급 DC를 중복 차감하지 않는다.
- 바코드 입력란의 상품명 검색 전환, 최근 거래일, 미등록 표시의 원본 동작.
- 같은 날 실사 상품의 수량 포함 여부, 재고관리/공급사 변경 체크와 선택 원자 반영.
- 기능 구획의 판가(고정/이익률)·분류·가격/공급사 반영 체크·특매가/정상가 전환.
- 여러 행/Ctrl/Shift 선택, 중복 상품 붉은 표시·선택, 매입일 후 판가 변경 상품 선택,
  분류·과면세·선택행 메모·가격의 일괄설정, 기존 특매그룹 추가.
  열 선택/보존은 적용했다. 단, 다른 PC로의 열 설정 공유나 설정 파일 백업 기능은 아님.
- 라벨 수량 전달/바구니, POP/ESL 출력/관리의 실제 연결.
- 선택 품목 전표 분리(원전표에서 제거·저장), 같은 공급사 합치기(원전표 0원 보존),
  별도 잠금/해제 권한. 결제·반품·마감·재고·동시 수정까지 함께 검증해야 한다.
- 단순 고객 주문서와 다른 공급사 발주서/무효/담당자/인쇄/중복 없는 매입 변환.
- 직매입 전용 수기 등록, 특정매입·판매분매입 자동 생성, 임대/수수료 공급사 구분.
- 공급사별/분류별/단품별/전표별 집계의 원본 필터·분류 계층 이동·일시 정렬·가중단가·
  보증금/세액·결제 상세 연결. 기존 집계가 있다는 이유로 상세 일치 완료로 표시하지 않는다.
- 이후 판매/실사 등 재고 이동이 있는 확정 매입의 원가 재계산, 확정 반품 자체 수정.
  현재는 해당 경우 수량/금액 변경을 안전하게 차단하고 메모/담당자만 허용한다.

## 전체 완료 전에 남은 결제 요구

- 신규 MIS 월마감과 미마감 과거 결제 묶음 정정/취소는 구현했다. 현재 월에서 최근
  6개 완료 월을 남기며 그 직전 월까지 마감한다(원본 예: 2020-06 실행 → 2019-11 마감).
  재고마감과 구분하고 원기록/이월 스냅샷을 보존한다. 미실행 시 실제 외상잔액을
  임의로 0으로 표시하지 않는다. 자동 시작 안내와 전체 회귀·Windows 검증은 남아 있다.
- 어음 정정 시 같은 어음번호를 유지하는 이력 연결은 미완료다. 현재 번호 중복 검증에
  걸려 해당 수정은 실패하며 기존 장부는 원자적으로 유지된다. 이 제한을 해결하기 전
  모든 결제 수정 완료로 표시하거나 운영용 최종본으로 배포하지 않는다.
- MIS 시작 월의 전기이월 버튼/공급사별 코드·이월금액 일괄 입력.
- 기타수수료(카드/포인트 등) 별도 집계와 공제잔액 설정. 기본 잔액에서 임의 차감 금지.
- 외상매입현황의 결제금액보기/예상지급액보기/결제율·DC 예측/열 선택.
- 공급사 외상매입 내역서의 매출/원가/이익 및 최근 60일 정책.
- MIS 매입현황의 일/월 매입·매출과 마감 매출 조건.
- 총계정원장의 계정과목 관리와 수입/지출 수정, 월손익의 VAT 포함/별도·전월 비교·
  월레포트 조건 및 원본 매출원가 산식. 현재 이동평균 판매원가 손익을 동일 산식이라고
  표시하지 않는다.
- 매출결제/회원별 거래내역·외상매출 관련 별도 전환/수정 흐름. 공급사 지급과 혼용 금지.
