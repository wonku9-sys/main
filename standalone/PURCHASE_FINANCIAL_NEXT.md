# 매입 상세 금액 다음 구현 계약 — 아직 미구현

이 문서는 상세 열의 표시 구현 이후, 상품장·전표·반품·집계에 금액 기록을 연결할 때
지켜야 하는 계약이다. 설계 문서이며 아래 기능이 구현되었다는 뜻이 아니다.

## 원본에서 확인한 규칙

- 상품등록정보 1쪽: 매입/판매단가는 부가세 포함 금액이다.
- 상품등록정보 1쪽: 포함기준가는 매입 DC율의 기준이다. 별도매입가는 공급가액이다.
- 상품등록정보 3쪽: 보증금은 별도 입력하되, 매입/판매단가는 그 보증금을 포함한다.
- 매입전표 등록 4쪽: 보증금은 공급가액 + 부가세에 포함되지 않는다.
- 최신 사용자 답변: DC금액/DC율은 펼쳐보기의 표시 항목이며 별도 팝업 동작이 아니다.
- 공급사 지급 D/C·장려금·쿠폰은 상품 기준가 할인과 다르다. 두 번 차감하지 않는다.

## 기존 원장에 대한 안전 조건

1. 기록 없는 기준가·보증금은 미기록(NULL)으로 유지한다. 명시적으로 확인한 0원과 다르다.
2. 현재 상품장 가격으로 과거 기준가·보증금·판매단가를 보충하지 않는다.
3. 단가에 포함된 보증금을 합계에 다시 더하거나 지급잔액에서 다시 차감하지 않는다.
4. 직접 입력한 매입금액과 단가 반올림 차이는 그대로 보존한다.
5. 원전표 수정으로 기존 결제·어음·할인 지급을 다시 생성하지 않는다.
6. 반품은 원거래의 단위·과면세·금액 구성 기록을 사용한다. 현재 상품장 설정은 사용하지 않는다.
7. 여러 번의 부분 반품에서 누적 차액을 배분해 마지막 반품까지 금액 구성 합계가 맞아야 한다.
8. 금액 기록·상품장 선택 반영·재고·감사 이력은 같은 트랜잭션으로 처리한다.
9. 재고/결제 마감, 후속 판매·실사, 연결 반품, 동시 수정 차단을 우회하지 않는다.

## 저장 경로 설계 시 함께 변경할 곳

- 상품장: 기준가/매입보증금/판매보증금 입력·검증·재조회와 과거 미기록 구분.
- 기본/박스/묶음/g/100g/kg: 기록의 금액 기준·단위·입수량을 명시하고 모든 경로에 동일 환산.
- `commerce.py`: 신규/초안/확정/반품의 금액 구성 스냅샷 생성.
- `purchase_amendments.py`: 변경 전후 구성 기록과 원가·결제 관계 보존.
- `document_entry` 또는 전용 원장: 누락/0원/실제 기록을 구분하는 명시적인 버전 자료.
- `recovery.py`: 현재 품목 입력 JSON은 정확히 sale_price/memo만 허용한다.
  따라서 화면에 추가 필드만 붙여 저장하면 복원이 실패한다. 검증·마이그레이션까지 같이 변경한다.
- 현재 장부 형식 218보다 구버전이 새 금액 구성의 의미를 모르고 수정하지 못하도록 버전 보호.
- `purchase_reports.py`, `purchase_reference_ui.py`, `purchase_output.py`: 집계·세액·PDF/엑셀을
  동일한 저장 기록으로 계산한다. 화면만 바꾼 뒤 기존 총액/11을 그대로 쓰지 않는다.
- `purchase_worksheet_view.py`: 미기록 표시를 실제 스냅샷 기반 계산으로 대체한다.
- 백업/복원·공유 PC 프로토콜·초기화도 같은 자료 구성을 검사한다.

## 구현 전에 계산 사례로 확정할 항목

할인 금액의 부호·0 기준가의 DC율, 보증금의 확장단위 기준, 과세/면세별 공급가액,
원 단위/소수점 VAT 반올림과 여러 행 합계의 원본 정책을 구체적인 사례로 대조한다.
설명서에 없는 정책은 원본 화면의 실제 입력/저장/출력 결과로 확인하며 임의로 정하지 않는다.

## 배포 전 검사표

- [ ] 일반/면세/보증금/할인 상품과 0원·미기록의 구분.
- [ ] 박스 입수량 변경, 중량·100g 기준, 금액 직접 입력의 소수점 잔차.
- [ ] 새 전표 저장/재실행, 초안 재개, 과거 상품장 변경 후에도 원기록 보존.
- [ ] 반복 부분 반품과 전량 반품의 구성 합계 일치.
- [ ] 지급 D/C와 상품 DC 동시 사용 시 잔액 중복 차감 없음.
- [ ] 수정·분리·합치기 도입 시 결제/어음/마감/재고 연결 보존.
- [ ] 공유 PC 충돌·응답 유실·중간 실패 전부 되돌림.
- [ ] 과거 버전 자료 보호 백업·변환·복원, 잘못된 금액 구성 거부.
- [ ] 화면·현황·인쇄·PDF·엑셀 합계 일치.
- [ ] Windows 실행파일 및 실제 매장 자료 사본으로 잔액 대조.
