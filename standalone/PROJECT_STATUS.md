# 진행 상태 · 2026-10-21 한국 시각

## 진행률 표시 기준 — rc35 확정 매입 수정 단계

이번 단계의 진행률은 아래 5개 작업 묶음의 완료 개수로 표시합니다. 기간/난이도 비중이나
PDF 전체 기능 완성률이 아닙니다. 현재 **100% (5/5)**이며 검증 도중 문제가 발견되면
해당 묶음을 다시 진행 중으로 표시합니다.

- [x] PDF 요구·장부 영향 분석
- [x] 원자적 수정·이력 보존 엔진과 기본 검사
- [x] 매입전표 화면·인쇄·PC 공유 연결 및 관련 검사
- [x] 전체 회귀·실행 검사 (Windows build3 전체 통과, 앱 소스 스모크 통과)
- [x] Windows 무설치 EXE·공개 다운로드 검증 및 배포 (build3 EXE·공개 ZIP 검증 완료)

rc35 build3: Windows 전체 1,048개, 125%/150% 각각 53개 및 실제 EXE의 73개 화면·
매입 수정/카드 보존/이력/0원 전표 검사를 통과했습니다. 공개 주소에서 Windows ZIP과
소스 ZIP 전체를 인증 없이 다시 받아 SHA-256·CRC·업무자료 제외·실행파일 x64를 확인했습니다.
[rc35 공개 다운로드](https://github.com/wonku9-sys/main/releases/tag/manual-purchase-v2.4.0rc35-build3)

기존 rc34는 Windows 전체 1,017개와 실제 EXE를 검증해 배포했습니다. 새 rc35의
Windows 검증 결과로 그대로 대신하지 않습니다. rc35에서 이후 판매/실사/반품에
연결된 품목 원가 재계산, 확정 반품 자체 수정, 별도 공급사 발주는 아직 미완료입니다.

## 전체 범위

전체 기능 목록·비중이 확정되지 않았으므로 전체 프로그램에 임의의 완성률
백분율을 부여하지 않습니다. 자동검사 통과를 실제 매장 검증 완료로 보지 않습니다.

사용자가 정한 목표는 **PDF 전체 기능·위치·과정을 단계별로 적용하여 원본과 100% 일치**입니다.
목표와 현재 완료율은 구분합니다. rc32는 연속된 매입 시트·단어와 맞는 3D 화살표/일괄입력
아이콘·새 전표 상세 결제·당일 결제 묶음 수정/취소를 구현하는 1단계입니다.
[PDF 구현 계획](PDF_IMPLEMENTATION_PLAN.md)에 장별 순서와 미완료 차이를 기록합니다.

효과 예외: 로그인은 닫힘만 페이드아웃, 프로그램 팝업은 180ms 열림/140ms 닫힘.
Windows 기본 파일선택·인쇄·확인창은 OS 동작을 유지합니다. Windows 애니메이션을
끄면 전환을 생략합니다. 일기·가계부 닫힘에는 개인 기록을 다시 그리지 않습니다.
