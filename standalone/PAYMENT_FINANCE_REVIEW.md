# rc25 결제관리 구현·검증 범위

## 근거

사용자가 첨부한 POS투게더 관리자프로그램 사용설명서 V0.93B의 인쇄쪽
146~153: 추가 사용자 확인, 공급사/기간/매입유무 조회, 공급사 더블클릭 거래내역,
전표 더블클릭 품목 내역, 현금·카드·이체 수기 기록, 당일 수정·삭제,
이력 보존, 인쇄 및 영업일보. 첨부한 MIS 화면은 6개 메뉴와 도구줄 그룹,
외상매입·공급사 거래내역·회원 거래내역·결제창·손익 화면 배치의 근거입니다.

어음·D/C·장려금·쿠폰을 실제 잔액에 반영하는 확장은 사용자가 별도로 승인했습니다.
사진이나 문서에 없는 승인 통신, 자동 송금, 세금계산서 발행 연동은 추정해 구현하지 않습니다.

## 사용

결제관리 진입은 현재 사용자 비밀번호로 추가 확인합니다. `1.외상매입` 메뉴에서
외상매입 → 공급사별 → 매입결제를 선택합니다. 거래 전표를 더블클릭하면 품목이
나옵니다. 공급사 선택 후 `결제처리`를 누르면 거래처/결제대상·할인/지급액 창이
열립니다. 매입장과 확정 매입전표의 결제 버튼도 같은 창을 사용합니다.

공급사 전체 결제는 초기 외상 → 오래된 매입전표 순서로 배분합니다. 매입전표에서
열면 선택 전표에만 배분합니다. 두 경우를 전표 표시와 배분 내역으로 구분합니다.
현금/계좌이체/카드 수기/어음과 할인 항목 합계가 결제 가능액을 넘으면 저장하지
않습니다. 다중 항목은 한 트랜잭션으로 모두 성공하거나 모두 취소합니다.

어음금액이 있으면 고유 어음번호와 만기일이 필요합니다. 발행은 공급사 외상을
어음 부채로 대체하는 기록입니다. 어음관리의 기본 조회는 미지급 전체이며,
만기일 기간 조회로 완료·취소 이력도 조회할 수 있습니다. 만기 지급은 실제로
지급한 날짜/현금·이체/메모를 기록하며 공급사 잔액을 다시 차감하지 않습니다.
발행/지급은 실제 은행 업무가 아닙니다. 이미 지급한 어음은 발행 취소하지 않습니다.

할인은 현금 지급과 별도입니다. 할인은 재고원가/부가세를 다시 계산하지 않고,
참고 손익의 기타 업무수입에 결제일 기준으로 포함합니다. 쿠폰은 합의한 정산액의
수기 기록이지 외부 쿠폰 검증·청구 기능이 아닙니다. 반품 시 할인과 어음 발행액을
현금 환급권으로 자동 전환하지 않습니다. 어음 지급 후의 환급·법적 상계는 자동
처리하지 않으며 상대 공급사와 실제 정산을 확인해야 합니다.

당일 현금/이체/카드 정정은 원기록 취소와 새 기록을 원자적으로 남깁니다.
어음·할인은 당일 원기록 취소 후 새 번호/내용으로 등록합니다. 지난 날짜의
결제 이력은 보존합니다. 결제 이력 조회의 취소 포함 여부를 선택할 수 있습니다.

`2.외상매출`은 기존 회원 외상한도·판매전표·반품·현금/이체 수금을 사용합니다.
회원 카드 수금 승인 기능은 추가하지 않습니다. 회원 검색 표시는 500명 단위의
검색 범위이며 공급사와 회원을 같은 거래처 번호로 혼용하지 않습니다.

`3.간편장부`의 계정원장은 매출·매입대금 외의 별도 업무 수입/비용 기록입니다.
개인 가계부와 무관하며 복식부기 총계정원장이나 세무 장부를 표방하지 않습니다.
참고 손익 = 확정 매출 − 저장된 판매원가 + 공급사 할인 + 업무 수입 − 업무비용.
전년동기와 월별 내역을 표시합니다. 미등록 비용/세금/감가상각은 제외합니다.
사진의 재고 공식에 맞추려고 근거 없는 기초/기말재고를 만들지 않습니다.

`4.레포트출력`은 실제 현재 조회 결과 출력과 영업일보, `5.마감관리`는 기존 현금·
월재고 마감으로 연결합니다. 현금 시재는 기존 판매 시재 범위를 유지합니다.
외부 업데이트/원격지원 서비스는 연결되지 않았으므로 비활성 및 안내 표시합니다.
`6.기타`로 매입장/첫화면에 돌아갈 수 있습니다. 이전/다음은 결제관리 하위 화면
이력을 읽기 전용으로 이동하며 그 전에 방문한 업무 화면으로도 돌아갈 수 있습니다.

## 보호·배포

장부 형식 215. 214 이하 결제 수단 제약 변경 전 자동 백업하고 트랜잭션 내
스키마 재구성·외래키 검사를 합니다. 이전 백업을 검증한 후 새 형식으로 복원합니다.
어음 연결 누락과 지급/취소 충돌은 복원 검증에서 거부합니다. 업무 초기화에는
어음/업무장부를 포함하며 개인 기록과 복구용 보호 백업은 보존합니다.

공개 업로드는 사용자의 사전 승인 범위에 따릅니다. 소스·생성 그림·실행 라이브러리만
배포하며 실제 업무 DB, 업로드 DAT/IDX, 초기화 인증파일, 개인 자료는 포함하지 않습니다.
새 파일명에는 2.4.0rc25와 아이콘3d가 포함됩니다. Windows 패키지는 실제 EXE
화면/새 결제 동작 검사를 통과해야 공개됩니다. 서명 없는 실행파일이므로 Windows
게시자/SmartScreen 안내가 완전히 사라진다고 보장하지 않으며 보안을 끄지 않습니다.
