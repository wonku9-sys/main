# 직원 권한 설정

관리자 모드 → 권한 설정에서 직원을 선택합니다. PDF p.142~145의 직원별 메뉴 체크 방식을 바탕으로 등록·수정·삭제를 더 세분화했습니다.

| 설정 | 동작 |
| --- | --- |
| 조회·접근 해제 | 해당 메뉴를 숨기고 다음 조회·출력에서 접근을 차단합니다. |
| 조회만 체크 | 자료 조회·허용된 출력은 가능하고 등록·수정·삭제는 불가능합니다. |
| 등록 체크 | 새 상품·전표·회원 등 해당 메뉴의 새 자료를 등록합니다. |
| 수정·편집 체크 | 기존 기초자료·초안 수정, 분류/단위 변경, 포인트 조정 등 해당 메뉴의 변경을 허용합니다. |
| 삭제·취소 체크 | 삭제 가능한 자료의 삭제, 전표 취소·반품, 결제 취소를 허용합니다. |

관리자 계정은 전체 권한이며 이 화면에서 제한하지 않습니다. 사용하지 않는 작업 칸은 비활성입니다. 직원은 자신의 권한이나 다른 사용자의 권한을 변경할 수 없습니다.

예: 상품장만 열어 상품 정보를 수정하는 직원은 상품장 행의 조회·접근과 수정·편집만 체크합니다. 상품 등록과 삭제는 차단됩니다. 먼저 등록된 분류 목록을 선택하는 것은 상품 편집 업무에 포함되지만, 임의의 새 분류를 만드는 것은 상품 분류의 등록 권한이 필요합니다.

결제는 직접 금액을 덮어쓰지 않고 당일 취소 후 다시 등록합니다. 정정 담당자는 결제관리의 등록과 삭제·취소 권한이 모두 필요합니다. 매입/매출 반품은 해당 전표 메뉴의 등록(또는 초안 수정)과 삭제·취소 권한이 필요하며, 실제 지급·환불은 별도 결제 권한도 검사합니다.

권한은 실제 SQLite 저장 처리 직전에 재검사합니다. 이미 열어 둔 편집창에서도 회수한 권한으로 저장할 수 없습니다. 권한 변경 후 메뉴 표시를 완전히 갱신하려면 해당 직원이 로그아웃 후 다시 로그인하세요. 기존 업무영역 권한은 자동으로 삭제하지 않고 호환하며, 새 설정에서 필요한 제한을 선택합니다.

권한 허용은 업무상 보호 규칙을 해제하지 않습니다. 마지막 관리자·현재 계정, 사용 중 분류, 확정 이력·마감된 기간·이미 환불한 결제 등은 관리자도 임의 삭제·수정할 수 없습니다. SQLite 파일 자체는 암호화되지 않으므로 Windows 계정·디스크 접근도 별도로 보호하세요.
