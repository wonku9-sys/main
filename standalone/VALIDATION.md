# 독립판 검증 기록

## 2.4.0rc14 · 상단 조회 중앙 배치

본창·독립 창의 조회 버튼을 대칭 측면 열과 가운데 열로 배치했습니다. 380/700/1000px 너비, 짧은/매우 긴 메뉴명, 첫화면·닫기 유무에서 버튼 중심이 조회 영역 중심과 1px 이내로 일치하고 좌우 버튼과 겹치거나 창 밖으로 나가지 않음을 확인합니다. 기존 메뉴 변경·내용 스크롤·팝업 크기 변경 검사에도 중앙 정렬 검사를 추가했습니다. F5·클릭 조회 일치와 미저장 확인을 유지합니다. 실제 동결 EXE의 화면 캡처마다 중앙 좌표도 검사합니다.

관련 집중 **19개 통과**, 최종 Linux 전체 **650개 통과·Windows 전용 1개 건너뜀**(123.43초)을 확인했습니다. CLI의 73개 메뉴·79개 PNG 및 조회 영역이 있는 모든 화면 캡처의 중앙 좌표 검사를 통과했습니다. 본창과 작은 독립 팝업 캡처를 확인했고 잠금파일의 오프라인 환경 설치도 통과했습니다. 실제 Windows 네이티브·동결 EXE와 게시 ZIP은 별도로 검증합니다. 장부와 암호 형식·MP3 기본음은 변경하지 않았습니다.

## 2.4.0rc13 · 승인된 MP3 6개 자동 기본음

사용자의 ‘MP3 6개 모두 공개 배포에 포함’ 명시 승인 후 원본 바이트를 복사했습니다. 6개 이벤트 매핑·고정 SHA256·새 설정의 자동 기본음·기존 사용자 파일 우선·이전 PC 파일 누락의 기본음 대체·개별 사용/음량 보존·기본 복원 시 원본 보존·미승인 MP3 배포 거부·실제 첨부 6개 PCM 디코딩을 검사합니다. 로그인 성공의 실제 기본 경로가 QMediaPlayer에 전달되는 것과 암호 실패/소리 꺼짐에서 재생되지 않는 것을 시험용 출력 장치로 확인합니다. 설정 창의 여섯 기본음·재생 오류 표시도 검사합니다. 실제 스피커 청취는 사용자 PC에서 확인해야 합니다.

사운드 집중 **18개 통과**, 최종 Linux 전체 **644개 통과·Windows 전용 1개 건너뜀**(117.30초)을 확인했습니다. CLI는 73개 메뉴·79개 PNG와 여섯 원본 MP3의 실제 PCM 디코딩을 통과했습니다. 설정 창 상·하단 캡처에서 자동 기본음과 개별 설정을 확인했습니다. 잠금파일의 오프라인 환경 설치와 소스 ZIP의 CRC·원본 해시·승인 MP3 정확히 6개 포함 및 개인 자료 배제도 확인했습니다. 실제 Windows 동결 EXE의 MP3 디코딩 및 게시 다운로드 ZIP은 별도로 검증합니다. 개인 음원/설정·DB·ROM은 계속 배포에서 제외합니다. 장부 구조와 암호 형식은 변경하지 않습니다.

rc12 Windows 사전 검사는 29개 통과·1개 실패였습니다. 실제 여섯 MP3 디코딩은 통과했고 로그인 미디어 호출도 원본 경로와 play 이벤트를 발생시켰지만, 검사의 문자열 경로가 Qt의 정방향 슬래시와 Windows 역방향 슬래시를 달리 판단했습니다. 동일 파일의 경로 객체로 비교해 정확한 파일·재생 횟수 검사를 유지합니다. rc12 ZIP은 게시하지 않았으며 rc13에서 다시 검사합니다.

## 2.4.0rc11 · 상품장·엑셀·과면세·변경로그·하단 바로가기

PDF 상품관리 20~24쪽과 제공 상품장/분류/변경로그 화면을 참고했습니다. 실제 XLS는 CP949 raw BIFF2, 35,190개 상품·23개 열·공급사명 145개이며 과면세/분류 열이 없고 통계 3행이 있습니다. 원본을 변경하지 않고 전 행을 분석했습니다. 별도 임시 시험 장부에서 추천 가능한 9,763개를 2.32초에 신규 등록하고 보호 백업 검사·재고/전표 미생성도 확인했습니다. 이 추천을 실제 세법 확정이나 사용자 장부에 등록 완료로 주장하지 않습니다. 시험용 복사본은 삭제했고 원본은 유지합니다.

- 자동 검사는 비상용 합성 BIFF2(20,000번째 행/CP949/손상), XLSX·통계 제외·바코드 앞자리 0·명시 과면세 우선·추천/미확정을 확인합니다.
- 새 상품만 생성·기존 자료 불변·소수 단가·보호 백업·중복 재등록·전체 롤백·권한 거부·별도 작업 연결, 분류 트리/빈 분류 필터·과/면 아이콘/텍스트·독립 상품창·회원지정가 권한과 Decimal·변경차/기준 0/문자 비율을 확인합니다.
- ‘나의 기록’ 하단 배치와 글자 폭 검사, 동결 EXE의 분류/과면세·상품 탭·변경로그·회원지정가·엑셀 미리보기 합성 화면 캡처를 추가했습니다. xlrd 2.0.2와 원본 라이선스도 함께 배포합니다. 사용자 원본 XLS·가격·공급사 자료를 배포하지 않습니다.
- rc10 Windows는 625개 통과·1개 실패였고, 실패는 Windows에서 즉시 두 이벤트의 monotonic 값이 같은 경계였습니다. 0초 경과도 유효한 우클릭으로 처리하고 같은 시각을 강제한 검사로 재현합니다. rc10 ZIP은 게시하지 않았습니다. rc11의 전체/Windows/실제 다운로드 결과는 별도 검증합니다.

최종 Linux 전체는 **633개 통과·Windows 전용 1개 건너뜀**(157.79초), 관련 집중은 36개 통과입니다. 새 미리보기 검사에서 빠진 시험용 규격 필드를 보완한 뒤 전체를 재실행했습니다. CLI는 73개 메뉴와 77개 PNG를 생성했고 상품장 분류·과면세, 변경로그, 하단 바로가기를 캡처로 확인했습니다. 잠금파일의 오프라인 개발환경 설치도 통과했습니다. Windows 네이티브·동결 EXE와 실제 게시 ZIP은 별도 배포 단계에서 확인합니다.

## 2.4.0rc10 · 문서·음수 재고·게임·복구·개별 사운드

초기 통합 Linux 전체 **610개 통과·Windows 전용 1개 건너뜀**, 문서 입력 배치·게임 영역/게임명 조정 후 집중 **70개 통과**를 확인했습니다. 후속 SNES·너구리·사운드 추가 후 전체는 620개 통과·1개 건너뜀·열기 소리 중복 검사 1개 실패를 확인했고, 접근성 화면 재배치 때 중복 Show를 한 번으로 합치도록 수정했습니다. 이후 관련 집중 **32개 통과**, 추가 설정 화면을 포함한 사운드 **6개 통과**, CLI **73개 메뉴·72개 PNG**를 확인했습니다. 최종 동일 소스의 전체 검사와 Windows 동결 EXE·DPAPI·다운로드 파일은 배포 작업에서 별도로 검증합니다. 고정 잠금파일 개발환경 설치도 통과했습니다.

PDF 18.1.1 환경설정·점포 일반을 확인했습니다. PDF에 주문서 상세 절차가 없어 제공한 화면을 기준으로 구현했습니다. 초기 Linux 전체에서 590개 통과·Windows 전용 1개 건너뜀·5개 실패를 확인했으며, 실패는 새 주문 메뉴 기대 목록 1개, 새 기본 음수 정책과 이전 차단 정책 검사 3개, 복구 동적 행 컨트롤 순서 1개였습니다. 차단 검사에는 정책을 명시해 기존 중복행/동시 입력/과거 월마감 검사를 유지하고, 별도로 기본 음수·실제 TLS 두 PC 동시 판매를 추가했습니다. 동적 표는 상품 ID 기반으로 복구하도록 수정했습니다.

- 문서·재고·메뉴 회귀 집중 98개, 주문·음수·로컬 TLS·게임·복구·실제 구형 구조/SMTP 집중 42개, 후속 메뉴/출력 집중 23개를 확인했습니다. 최종 전체 검사는 별도로 실행합니다.
- 실제 양수 제약의 구조 211 DB를 만들어 212로 변경하고 자동 원본 백업, 금액/ID/외래키/트리거/이전 견적서 보존 및 구형 보호 백업 재검증을 확인합니다. 금액은 Decimal·수량은 천분율 정수이며 근거 없는 금액 초기화는 하지 않습니다.
- 주문 저장 무전표/무재고, 점포 스냅샷, 상태/배달일 조회, 같은 주문의 두 클라이언트 동시 판매 1건, 취소·권한·실패 전체 롤백, 부족 재고 정확한 수량·원가·취소·실사·붉은 표시를 검사합니다. 원가 차이는 잠정으로 표시하며 실사로 명시 조정합니다.
- A4 HTML의 사용자 입력 이스케이프, 소수 금액·과면세·100g 기준, 실제 PNG/PDF 파일, SMTP 이미지 첨부/수신 주소/암호화 설정/작업 후 메모리 비우기를 시험용 SMTP로 확인합니다. 실메일·실물 프린터는 검증하지 않습니다.
- 여섯 자체 게임의 엔진·입력·충돌/득점·오목 AI 방어·코인/점프/버블·너구리 사다리/과일/시간/목숨/스테이지·독립 창·일시정지·점수 중복 방지/원자 저장을 검사합니다. 등록된 상용 ROM을 실행한 검사가 아닙니다.
- 실제 첨부 NES 3개·SNES 1개·오락실 ZIP 2개의 헤더/크기/CRC/SHA256과 로컬 복사 등록을 확인했습니다. 자동 검사는 자체 생성한 비상용 테스트 파일로 중복 등록·원본 보존·경로/손상 거부·SNES 복사기 헤더 유무·셸 없는 인자·명시 실행·수동 점수를 확인합니다. ROM/에뮬레이터를 공개 저장소·배포 ZIP에 포함하지 않으며 실제 외부 원작 실행은 미검증입니다. 공식 FCEUX/Snes9x/MAME 안내 링크는 읽기 전용으로 확인합니다.
- 업로드 MP3는 공개 배포하지 않고 내 PC에 등록합니다. 실제 6개 파일의 MP3 형식·길이를 ffprobe로 읽기 전용 확인했습니다. 자동 검사는 별도 열기/추첨/로그인/경고/왼쪽 클릭/오른쪽 메뉴 설정·원본 보존·음량/차단·로그인 성공/실패·중복 재생 방지·닫기 중지·기본 경고/독립 팝업 라우팅·메뉴 실제 열림 조건·배포 파일 배제를 확인합니다. 실제 스피커 청취는 검증하지 않습니다. 샌드박스에서 차단된 로컬 TLS 17개는 통신 허용 환경에서 재실행해 네트워크 검사 24개 모두 통과했습니다.
- 임시 전표 복구의 무저장/무재고, 파일 내 평문 부재, 개인 자료키 없는 접근·잘못된 키 거부, 암호 필드 미보관, 메뉴 글자 폭과 점포 연결을 검사합니다. Windows 동결 EXE 스모크는 실제 DPAPI 보관·복호와 복구 화면도 확인합니다. 일반 보조창의 자동 원위치 복귀를 모두 지원하는 것으로 주장하지 않습니다.

rc8 Windows 전체 검사는 585개 통과·1개 실패였고, 실패는 1028×749가 한계인 CI 바탕화면에서 1100×760을 요구한 새 테스트였습니다. 여러 크기 조절 검사는 화면 안의 700×500·900×650·760×540으로 수정했습니다. 실패한 rc8 Windows ZIP은 게시하지 않았습니다. 최종 rc9 결과는 별도로 기록합니다.

## 2.4.0rc8 · 고정 조회·창 크기 조절

메뉴 변경/내용 스크롤 중 조회 버튼 위치, 버튼과 실제 F5의 동일 화면 조회, 미저장 설정의 조회 취소, 독립 업무 창의 고정 상단, 크기 조절 손잡이·기본 창 테두리·최대화 플래그, 여러 크기로 축소/확대, 전체화면 복원, 작은 상품 등록창의 내용 스크롤과 별도 닫기 접근성을 검사합니다. 실제 동결 Windows EXE에서도 작은 독립 창을 스크롤한 고정 조회 화면을 캡처합니다. 자동 크기 변경 검사는 마우스로 네 모서리를 직접 드래그한 하드웨어 검사를 대신하지 않으며, 실제 모니터 배율과 마우스 조작은 사용자 PC에서 확인해야 합니다.
