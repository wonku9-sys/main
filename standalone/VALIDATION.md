## rc24 · Windows 선행 검사 보완

두 번째 Windows 빌드에서는 호버 검사에 공유 네이티브 커서의 비동기 위치가
섞이는 문제가 나타났습니다. 테스트에서 실제 Qt Enter/Leave/MouseMove 이벤트를

비활성/이탈 복원·클릭 비실행·GC 수명에 대한 검증은 그대로 유지합니다.

런타임은 rc24와 같으며 새 태그 `standalone-v2.4.0rc24-build2`로 확인합니다.

rc23 Windows 선행 검사에서 139개 통과 후 두 문제를 발견했습니다.
음원 테스트의 파일 경로 구분자 비교는 Path로 정규화하고, 매입 입력 단위
선택칸이 최소 폭보다 1픽셀 작아지는 문제는 실제 위젯 최소 폭과 셀 여백을
반영해 보정했습니다. 검사를 건너뛰거나 기준을 낮추지 않았습니다.
rc23 실패 빌드는 배포하지 않았고, rc24를 새 태그로 검사합니다.
선행 검사는 새 기능·Windows 차이 위주로 줄이고, 전체 검사·회원/카드 재검사·
실제 EXE 빌드와 실행 검사는 그대로 유지합니다.

## rc22 · 아이콘3d 변형

### 메뉴 호버 밝기·아이콘 확대

메뉴 아이콘의 일반/호버 두 렌더링을 캐시하고 고정 아이콘 슬롯 안에서 중앙 120px→원본 128px(약 6.7%)로 표시합니다. 원본 PNG·아이콘 슬롯·버튼/행/글자 배치를 바꾸지 않으며, 이탈/숨김/비활성화 시 복원하고 선택/실행은 클릭에만 따릅니다. 스킨 바탕색에 흰색을 18% 혼합한 Light 팔레트를 사용해 눈부신 고정 흰색 대신 밝기를 조금 높입니다. 로그인 선택/호버의 기존 청회색·세이지 대비는 보존합니다. 반복 타이머는 없고 상태 이미지를 재사용합니다.

실제 도구모음 검사에서 C++ 생성 버튼의 Python 필터 상태가 수거되는 문제를 발견해 소유 위젯 파괴까지 필터를 유지하도록 수정했습니다. GC 후 메뉴 이동/활성화·상태 복원과 위젯 삭제 시 해제를 재검증했습니다. 최종 관련 **100개 통과**(32.48초), 실제 CLI **73개 메뉴·PNG 97개**와 전표/결제/백업/복원/종료/격리 초기화가 통과했습니다. 마우스 진입/이탈·확대 픽셀 수·고정 크기·비활성 클릭 차단·좌측 선택 보존·다섯 스킨 밝기·출력 잘림·배율·기존 단축키/도움말을 검사했습니다. 상단/좌측/하단 개인 메뉴와 로그인 호버 미리보기는 가상 자료로 생성했습니다. Windows EXE 빌드/실제 화면 검증/공개 배포는 여전히 완료 전입니다.

### 일기장·가계부 실사풍 3D와 부드러운 전환

전용 투명 1254×1254 PNG 두 장을 생성해 메뉴·로그인·창 아이콘에 공유했습니다. 진입 제목에는 52px, 실제 기록 창 제목에는 44px 장식을 추가하고 본문·암호화·잠금은 유지합니다. 무결성·원본 PNG/소스 ZIP 포함·18/26/36/44/52/88/108px 투명 가장자리·같은 캐시·로그인/하단/좌측/제목 연결과 개인 창 재사용을 검사했습니다. 최초 개인 기록 관련 **68개 통과**(19.60초).
