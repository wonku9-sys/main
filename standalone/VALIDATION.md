## 2026-10-19 클라우드 검증

기존 앱과 분리된 `standalone/.venv`를 새로 만들고 `standalone/uv.lock`에서 의존성을 설치했습니다. 다음 명령을 실제 실행했습니다.

```bash
cd /workspace/main/standalone
bash setup_cloud.sh
```

결과: **162 passed**, 전체 19개 업무 화면 스모크 통과. 임시 데모 DB에서 확장단위 매입·판매, 원전표 부분 반품, 회원 포인트와 자료 재열기를 확인했습니다. 실행 중 기존 `seoyoung_pos` 패키지가 import되지 않았음을 검사합니다. 스모크는 실자료 DB를 사용하지 않습니다.

## 실기기 시험과 한계

물리 USB 리더기·라벨 프린터·일반 프린터는 클라우드에 연결되어 있지 않습니다. 실제 매장의 장치 동작이 검증됐다는 뜻은 아닙니다. USB HID 종료 문자 Enter/Tab, Windows 드라이버, 실제 라벨 규격을 설정한 뒤 라벨 1장 출력·스캔 시험이 필요합니다.

원가의 과거일자 자동 재계산, 고급 쿠폰·복합행사, 원본 규격 Excel 수입, 단축상품 프리셋, 원본 데이터 변환 등은 미구현이며 `MANUAL_ANALYSIS.md`에 명시했습니다. 세금 신고·승인 기능이나 실매장 사용 적합성을 자동 테스트만으로 보증하지 않습니다. 처음에는 백업과 소량의 확인 거래로 점검하세요.
