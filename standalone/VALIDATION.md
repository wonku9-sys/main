# 독립판 검증 기록

## 2026-10-19 클라우드 검증

기존 앱과 분리된 `standalone/.venv`를 새로 만들고 `standalone/uv.lock`에서 의존성을 설치했습니다. 다음 명령을 실제 실행했습니다.

```bash
cd /workspace/main/standalone
bash setup_cloud.sh
```

2.1.0 검증 대상은 **230개 테스트와 21개 업무 화면**입니다. 임시 데모 DB에서 확장단위 매입·판매, 원전표 부분 반품, 회원 포인트와 자료 재열기를 확인합니다. 실행 중 기존 `seoyoung_pos` 패키지가 import되지 않았음을 검사합니다. 스모크는 실자료 DB를 사용하지 않습니다. 초기 admin/1234 안내·해시 저장·비밀번호 변경 후 초기화되지 않음·기존 사용자 보존도 검사합니다. Windows 릴리스의 최종 통과 결과는 해당 태그의 Actions 기록으로 확인합니다.

추가 검증은 백업 선택·주의창·비밀번호·전체 자료 복원·복원 전 보호 사본·실패 롤백, 손상/다른 앱/실행 중 WAL/다른 버전 거부, 복원 후 다른 연결 세션 무효화, 주간 20→15 정리와 알림·최신 15개 보존·외부 파일 비삭제, 상품코드 동시 생성/삭제/복원 후 번호 비재사용, 분류 트리 3단계/이름 전파/사용 중 삭제 방어, 등록된 분류만 선택, 공급사/기간 매입 조회, 공급사 상품 제한 체크 해제와 다중 선택, 환산 수량과 미지급잔액을 포함합니다.

결제관리는 초기 외상과 여러 전표의 FIFO 부분 배분, 한 결제/여러 실제 배분의 이중 집계 방지, 기간 이월·전체/매입 있는 공급사, 과다·미래·거래 전 날짜·최신 권한·중복 입력 방어, 중간 배분 실패 시 전체 롤백, 당일 묶음 전체 취소·지난 날짜/마감/환불 연결 차단, 손상된 결제 배분 백업 거부와 정상 백업 복원, 활성 탭 엑셀·실제 Qt 결제 팝업을 검사합니다.

이전 2.0.1 Linux 동결 실행파일은 19개 화면 스모크를 통과했습니다. 이는 **이번 Windows 실행 검증과 다릅니다**. 2.1.0 Windows 릴리스는 별도 `standalone-windows.yml`에서 네이티브 Windows 2022 x64 환경의 동일 테스트, 새 EXE에서 21개 화면·실제 백업 생성/복원·재로그인, 상품장/매입전표/공급사 상품검색/분류/백업/결제관리 화면 PNG 생성, ZIP CRC·SHA-256을 통과한 경우에만 게시합니다. 릴리스 페이지의 태그와 GitHub Actions 실행 기록으로 결과를 확인할 수 있습니다.

2.0.0의 Windows offscreen 화면 검사에서는 글자가 네모로 나타나는 문제를 확인했습니다. 2.0.1은 공식 OFL 라이선스의 Noto Sans KR를 로컬 자산으로 동봉하고 화면·PDF·라벨에 명시적으로 적용합니다. 한글·영문·숫자의 실제 글리프 포함 여부를 검사하며, Windows 테스트와 동결 EXE 캡처는 실제 사용과 동일한 `windows` Qt 플랫폼에서 수행합니다. 외부 폰트 다운로드·Windows 한글 언어팩에 의존하지 않습니다.

## 실기기 시험과 한계

물리 USB 리더기·라벨 프린터·일반 프린터는 클라우드에 연결되어 있지 않습니다. 실제 매장의 장치 동작이 검증됐다는 뜻은 아닙니다. USB HID 종료 문자 Enter/Tab, Windows 드라이버, 실제 라벨 규격을 설정한 뒤 라벨 1장 출력·스캔 시험이 필요합니다.

원가의 과거일자 자동 재계산, 고급 쿠폰·복합행사, 원본 규격 Excel 수입, 단축상품 프리셋, 원본 데이터 변환 등은 미구현이며 `MANUAL_ANALYSIS.md`에 명시했습니다. 세금 신고·승인 기능이나 실매장 사용 적합성을 자동 테스트만으로 보증하지 않습니다. 처음에는 백업과 소량의 확인 거래로 점검하세요.
