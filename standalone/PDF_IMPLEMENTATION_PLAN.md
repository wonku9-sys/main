## 현재 확인한 1단계 동작

- 공급사 → 상품검색 → Space 즉시 추가 → 수량·단가/직접 금액 → 저장 확인 → 상품장 가격 변경 선택.
- 달력·시분·담당자, 입수량·총수량·품목 메모·정확한 반올림 차이를 보존.
- 상세 결제는 새 전표에서는 계획으로만 보관하고 전표 확정과 함께 원자 반영.
- 결제율/대상액, D/C/장려금/쿠폰/기타, 현금/이체/카드 수기/어음, 일시·계좌·메모.
- 당일 결제 묶음 정정·취소 시 원기록 보존, 잔액 복원, 다른 PC 변경·마감·지급 완료 어음 차단.
- 위로/아래로는 입체 화살표, 일괄입력은 시트·연필 그림. 행 이동으로 입력 메모·금액을 잃지 않음.
