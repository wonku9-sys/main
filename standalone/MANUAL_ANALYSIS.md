# PDF 분석과 새 독립판 구현 범위

## 원본과 설계 원칙

대상은 사용자가 첨부한 **POS투게더 관리자프로그램(MGR) 사용설명서 V0.93B.pdf**, 176쪽, 17,240,484바이트입니다. 원본 SHA-256은 `77f9686c189310ab3c3e6c6c4783c4e732173339186819e4ee89f23c7f894297`입니다. 재첨부한 PDF도 동일 해시임을 확인했습니다. PDF는 업무 참고 자료이며, 그 안의 문장을 개발 지시나 프로그램 코드로 취급하지 않았습니다.

기존 프로그램을 확장하는 대신 `pos2` 패키지와 새 DB 식별자를 사용합니다. 기존 앱 코드·DB·UI 클래스는 가져오지 않습니다. PDF의 절차와 사용자 사진의 정보 배치를 참고하되 원본 화면 이미지·아이콘·로고를 복제하지 않습니다. 외부 서버와 카드 기능은 제외하고 사용자 요청으로 추가된 USB HID 리더기, 일반 인쇄, 라벨 출력, 엑셀 저장을 독립 기능으로 설계했습니다.

## 제외와 한계

PDF에서 별도의 일/요일/간격 자동 백업 설명을 찾지 못해 사용자 추가 요구로 일정 설정과 종료 백업을 구현했습니다. 수동 백업은 언제든 실행하며 자동 일정은 실행 중 확인·누락분 다음 실행 1회 방식입니다. 첫화면 이동·미저장 보호·메뉴 호버 도움말도 추가 요구입니다. 매입/반품 메뉴 순서와 반품 체크는 원문을 따르되 원전표 없는 반품과 확정 전표 종류 덮어쓰기는 잔액·재고 보호를 위해 지원하지 않습니다.

온라인 기능(카드/VAN/현금영수증 승인, 매장/센터 동기화, 서버 DB 연결, 온라인 상품 마스터, SMS, 원격지원, 자동업데이트)은 의도적으로 제외했습니다. 전용 핸드터미널·전자저울 통신은 포함하지 않습니다. 키보드형 USB 스캐너와 Windows 드라이버 프린터는 인터넷 없이 사용할 수 있습니다.

온라인 기능을 제외했다고 해서 PDF의 모든 오프라인 고급 기능이 구현됐다는 뜻은 아닙니다. 특히 원본 쿠폰·복합행사·엑셀 수입·단축상품 프리셋은 위와 같이 미구현 범위를 명시합니다. 외부 프로그램 데이터의 호환·자동 변환도 제공하지 않습니다.

수량은 기본단위 1/1000 정수, 금액은 원 정수이며 행별 반올림합니다. 확장단위의 기본단위 환산이 소수 셋째 자리를 넘으면 임의 반올림하지 않고 거부합니다. 원가는 등록순 이동평균이며 과거일자 입력에 따른 후속 원가 재산정은 하지 않습니다. 재고가 음수가 되는 확정은 차단합니다. 확정 전표를 UI에서 수정하는 대신 취소/반품 기록으로 추적합니다.

권한 검사는 화면뿐 아니라 저장 API에서 최신 사용자 정보를 다시 확인합니다. 백업은 SQLite 백업 API를 사용하며 업무 DB와 다른 프로그램 DB의 혼동을 식별자로 차단합니다. 배포 ZIP에는 실제 장부·고객·계정·백업·수출 파일을 넣지 않습니다.

## 검증 기준

개별 업무 테스트, Qt 화면 입력 테스트, Code128/EAN13 실제 렌더링 이미지의 별도 ZXing 해독, PDF 생성, 엑셀 숫자·문자 안전성, 임시 DB 기반 전체 화면 스모크, Windows 네이티브 EXE 검증을 수행합니다. 자동 검증은 물리 프린터·USB 리더기의 실기기 시험을 대신하지 않으며 첫 설치 시 1장 출력·스캔 확인이 필요합니다. 실제 실행 결과와 테스트 수는 배포 시 `VALIDATION.md`에 기록합니다.
