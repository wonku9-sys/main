2. 안의 `SY-POS/SY-POS.exe`를 실행합니다. Python 별도 설치가 필요하지 않습니다.
3. `runtime`·`app`·`licenses` 폴더를 함께 두세요. EXE만 옮기면 실행되지 않습니다.
4. 기본 자료는 이 시험판 폴더의 새 `trial-data-v2`입니다. 처음에는 새 관리자 계정을 만듭니다.

6. 한자 풀이, 글귀 복사 후 메모장 Ctrl+V, 달력 이전/다음, 완료 체크 아이콘을 확인하세요.
