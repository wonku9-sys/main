# SY POS 전용 이미지 로고

사용자의 SY 이미지 브랜딩 요청으로 새로 생성한 에메랄드·샴페인 골드 SY 모노그램입니다.
외부 회사의 로고나 PDF의 로고를 복사하지 않았습니다. 작은 창 식별용 아이콘과 Windows 실행 아이콘에 사용합니다.

원본 생성 이미지: `sy-monogram.png` (투명 배경 PNG).
이 파일에는 매장 데이터·개인 정보·계정 비밀번호가 없습니다.

## SY POS 3D 워드마크

`sy-pos-wordmark-3d.png`는 사용자의 요청으로 새로 생성한 투명 배경 2172×724 PNG입니다.
청록색 에나멜 전면과 은색 금속 입체 테두리로 **SY POS** 전체 문구를 표현했습니다.
SHA256: `60fba2d4721ac0c999a23d1655b3d5cfd9189e05531fb6fd6a262efebe5a8797`

후속 광원 요청에 따라 왼쪽 위에서 빛을 받는 청록 반사면과 더 밝은 은색 모서리, 작은 광택 포인트를 이미지 자체에 표현했습니다. 움직이는 빛·깜빡임이나 별도 그래픽 효과 필터는 추가하지 않습니다. 동일 크기와 기존 캐시 방식을 유지합니다.

- 업무 도구모음: F8 스캔과 오른쪽 테두리 사이 남은 공간의 중앙, 156×52 논리 픽셀 로고. 가변 폭 영역의 양쪽 동일 비율 여백으로 창 확대·축소에 맞춰 중앙을 유지합니다.
- 첫 로그인: 왼쪽 선택 패널 상단, 216×72 논리 픽셀 영역.
- 박스·하얀 배경·별도 POS 글자 없이 동일한 이미지 한 장을 사용합니다.
- 2배 해상도로 축소하여 HiDPI에서 선명하게 표시하고, 이미지는 한 번 읽어 재사용합니다.
- 프로그램 실행 중 외부 다운로드·네트워크·움직이는 효과를 사용하지 않습니다.
- 기존 `sy-monogram.png`와 창 아이콘, 메뉴의 크기·기능·단축키는 보존합니다.

로그인 선택 패널은 청회색 그라데이션(`#243C48`→`#35515D`)과 차분한 메뉴 바탕(`#365563`)을 사용합니다. 선택 항목은 세이지(`#CADCD2`)와 짙은 글자(`#244B42`), 마우스/키보드 포커스는 별도 은은한 색상으로 표시하며 3D 로고 이미지는 바꾸지 않습니다.
