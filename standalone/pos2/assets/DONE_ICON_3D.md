# 완료 버튼 3D 아이콘

사용자가 제시한 파란 원과 흰 체크 모양을 참고해 이 프로그램용으로 생성한 단일 아이콘.
실사풍 광택·베벨·입체 체크, 투명 배경 PNG. 체크무늬 배경은 그림에 포함하지 않는다.
`done-real3d.png` 원본을 보존하며 Qt가 버튼 크기에 맞게 비율을 유지해 표시한다.

- 파일 SHA-256: `220971e75a7b484b4d1fca4cf348c4d23abb04ad200b5d35603d0210c9c13e0f`
- 용도: 완료·확인 및 완료 상태 표시. 완료 취소에는 성공 체크를 사용하지 않는다.
- `package_source.py`와 Windows 전체 assets 패키징에 포함한다.
- 외부 URL이나 사용자 업로드 원본 그림에 실행 중 의존하지 않는다.
