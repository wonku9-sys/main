## 추가: 상단 조회 F5 경로 수정

클릭은 현재 화면의 고정 조회 버튼에 연결되지만, 기존 공통 F5는 마지막으로 활성화한
메뉴의 current_key를 사용했다. 매입 목록을 본화면에 두고 상품장을 독립창으로 연 뒤
본화면으로 돌아오면 클릭은 매입, F5는 상품장을 조회하는 실패를 자동검사로 재현했다.

현재 보이는 QueryBar가 창 범위의 F5를 하나만 소유하고 실제 조회 버튼을 클릭하도록
통일했다. 기존 공통 QAction의 중복 F5 바인딩은 제거하고 직접 호출 기능은 유지한다.
검색/날짜/공급사/표/트리 포커스와 독립창 전환을 검사했다. 숨김·비활성 조회 버튼,
미저장 편집 취소 확인을 우회하지 않으며 매입 작성창·상품검색창은 자체 F5를 유지한다.

결제확인 O. 새 요구와 기존 기능의 차이·정확한 제한은
[전체 요구 추적](MGR_PURCHASE_PAYMENT_SCOPE.md)에 기록한다.
MIS 월마감과 미마감 과거 결제의 묶음 정정/취소를 추가했다. 상세형 초안은 교체가 필요하다.
월마감 추가 이전 소스 검증: 전체 1,098개 통과/1개 건너뜀, 집중 110개,
125%/150% 각 33개, 실제 소스 앱 73개 화면 통과. 근거 로그는 위 요구 추적 문서 참조.

2026-10-22 새 개별 설명서 45개/108쪽을 수신하고 본문 추출을 확인했다.
[최신 매입·결제 요구 대조](MGR_PURCHASE_REVIEW_20261022.md)와
[자료 목록·해시](MGR_REFERENCE_INDEX_20261022.md)를 우선 참조한다.
이는 모든 문서 분석/기능 구현 완료가 아니다.

기준: 기존 PDF 12~19쪽의 매입 등록 순서, 최신 우클릭·행/셀 선택·기본/상세 보기 캡처.
rc35 공개 실행파일과 이 작업 중인 소스를 혼동하지 않습니다.

## 구현 및 집중 검사한 범위

- Qt 공식 한국어 번역을 앱 시작부터 로드하고 실행파일 패키지에 직접 포함하도록 변경.
  표준 입력칸·메모·수량·날짜·콤보의 우클릭 메뉴와 실제 복사/붙여넣기 검사.
- 매입반품 표시를 `반품`으로 변경하고 매입장 구분 글자를 음수 금액과 같은 #B42318로 표시.
- 부가정보(F11): 오른쪽에 상품명·바코드, 확정 매입일/매입가/당시 기록 판매가와 행사기간 표시.
  선택 상품·단위·매입일에 맞게 갱신하고 박스/기본단위/100g 가격을 동일 기준으로 환산.
  미저장·초안·취소·반품은 추이에서 제외. 과거 판매가 기록이 없으면 현재가로 채우지 않음.
  연한 붉은 배경은 이전 매입과 가격이 달라진 기록. 현재 전표는 굵게 표시.
- 번호·상품명·규격은 같은 연한 배경. 왼쪽 클릭은 행 선택, 오른쪽 클릭은 단일 셀 선택/편집.
- 선택 상품 우클릭: 인쇄(그리드/출력양식), 엑셀, 상품정보, 가격 이력, 매입수정,
  위/아래 이동, 기존 일괄입력, 선택행 메모/삭제, 과면세 정보와 기본 셀 편집에 연결.
  저장 전에는 장부·재고에 반영하지 않으며 읽기 전용/수정 제한 상태를 유지.
  최신 지시대로 빈 회색 영역과 표 머리글에도 같은 메뉴를 표시하고 기존 선택을 유지.
- 우클릭 하위 메뉴의 QAction 래퍼 수명 문제를 재현하고 메뉴 참조를 유지하도록 보완.

Linux 관련 집중 검사 47개 통과(8.90초). 행/셀 선택과 우클릭을 추가한 소스 실행에서
73개 화면을 통과하고 실제 캡처를 확인했다. 그 이후 빈 회색 영역/머리글 추가는
위 47개 검사에서 확인했으며 새 Windows EXE/배율/전체 회귀 검사는 별도로 필요.
무지연·실제 장비·전체 PDF 동일 구현 완료를 주장하지 않음.

## 최신 캡처 대조 — 금액 저장/계산은 배포 전 보완 필요

처음 만든 줄여보기 초안은 현재 열 일부를 숨기는 방식이었다. 이후 받은 명확한 캡처는:

- 줄여보기: 기존 기본 열(바코드/수량/입수/총수량/매입금액/매입단가/판매가/이익률/분류/공급사/재고/메모).
- 펼쳐보기: 기준가·기준가액·할인·할인율·공급단가·공급가액·부가세·보증금·낱개이익·판매가액·예정이익·구분 등의 상세 열과 DC금액/DC율 및 하단 DC 합계가 추가됨.

기본/상세 열 구성은 현재 소스에서 위 기준으로 교체했다. 할인·보증금 저장·계산 규칙은
미완료이므로 이를 최종 구현으로 배포하면 안 된다. 0이나 현재가로 모르는 값을 채우거나
전표 할인과 공급사 지급 할인을 중복 차감하지 말 것.

사용자는 DC금액/DC율은 별도 작동이 없고 펼쳐보기에서 표시된다고 답했다.
따라서 별도 DC 팝업을 새로 만들거나 같은 질문을 반복하지 않는다. 새 상품등록 문서의
포함기준가/매입DC율과 매입·판매 보증금 설명을 상세형 데이터 설계에 함께 적용한다.
전체 우클릭 메뉴 하단은
새 캡처에서 `ESL 관리`, `매입전표 잠금`, `열 선택`까지 확인했다. 하위 기능은 아직 미대조.
라벨/POP, 분류·과면세 일괄, 판가변경/중복 선택, 전표 분리·합치기·잠금 등은
현재 우클릭 기본 기능 구현과 구분한다. 실제 구현 없이 성공하는 메뉴를 만들지 않는다.

Windows 새 배포는 위 상세 보기 차이를 해소하고 전체 검사 및 실제 EXE를 통과한 뒤 진행.
자료 경로 `data-v2`는 유지하며 MIS 월마감 때문에 장부 형식을 218로 올렸다.
217 자료를 열 때 보호 백업을 남긴다. 변환한 자료를 rc35에서 열지 말고 시험 사본만 사용한다.
월마감 추가 후 전체 회귀 및 Windows 실행파일 검증은 아직 진행하지 않았다.
