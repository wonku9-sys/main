# rc22 · 아이콘3d 대조 기록

참고 자료는 사용자 첨부 MGR 설명서 13쪽(전표/상품 검색), 99쪽(회원조회/등록) 및 대화의 상단 1~4줄 메뉴 캡처입니다. 문서의 이미지 배치·상대 크기를 참고했으며 PDF가 특정 픽셀 수를 규정하지는 않습니다. 원본 로고·아이콘은 추출해 사용하지 않았습니다.

| 구역 | 적용 크기 | 원칙 |
| --- | --- | --- |
| 상단 주요 메뉴 | 아이콘 38px, 메뉴명 14px | 박스 없는 독립 물체, 아래 메뉴명, 구분선 유지 |
| 번호 메뉴줄 | 글자 13px | 숫자/문자 위주로 간결하게 유지 |
| 좌측 메뉴 | 아이콘 18px, 글자 14px, 항목 최소높이 19px | 한 그룹 펼침과 긴 이름 가로 스크롤 유지 |
| 업무 표/입력 | 기본 글자 14px, 표 행높이 35px | 가로 열은 조절/스크롤, 글자를 과하게 축소하지 않음 |
| 결제 작업 아이콘 | 34px | 현금/카드/이체/정정/취소를 다른 모양으로 구분 |
| 우측 출력 | 아이콘 28px | 인쇄/엑셀 각 하나, 설명/단축키 유지 |
| 하단 개인 메뉴 | 아이콘 26px | 투명 바탕·현재 위치 유지 |

위 값은 Qt 논리 픽셀입니다. 운영체제 배율을 강제로 100%로 고정하지 않습니다. 그림은 실제 물체를 닮게 새로 생성한 3D 렌더링이며 실제 촬영사진은 아닙니다. 투명 배경 아틀라스 하나를 오프라인으로 읽고 계열별 최대 32개 캐시를 공유합니다.

기본 배경은 쿨그레이 `#E2E8E8`, 표 머리글은 세이지 `#D6E2D6`, 입력 바탕은 `#F0F4F4`입니다. 주요 본문 `#243A48`과 기본 배경의 계산상 대비는 약 9.55:1, 입력 바탕과는 약 10.68:1입니다. 이는 해당 색 조합의 수치이며 전체 UI의 접근성 인증이나 눈 피로 예방을 보장하지 않습니다. 분홍색 금액 칸·빨간 반품/음수·황색 경고는 유지합니다.

업무 기능과 자료 구조 214는 변경하지 않습니다. 큰 글자 적용 후 하단 개인 메뉴 버튼의 실제 글꼴 폭을 계산하도록 보정했고, 좁은 창·메뉴 이동·중앙 조회·출력 아이콘·키보드 동작을 회귀 검사합니다.

파일명은 `SY-POS-v2.4.0rc22-Windows-x64-portable-아이콘3d.zip`(Windows 실행파일)과 `SY-POS-v2.4.0rc22-source-아이콘3d.zip`(수정 소스)으로 구분합니다. 소스 ZIP을 Windows 실행파일로 안내하지 않습니다. Windows 빌드/검증/공개 배포가 완료되기 전에는 실행파일 다운로드가 완료됐다고 표시하지 않습니다.
