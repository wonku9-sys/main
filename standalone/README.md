이번 버전은 가계부 재무·예산·목표·맞춤 보고서, 일기장, 물류 업무일지, 상세 차량기록부와 선택형 PC 공유를 제공하는 검토용 미리보기입니다. 실제 은행·카드 연동이나 문자 자동 발송은 하지 않습니다. 원본 설명서 전체를 동일하게 복제한 제품은 아니며 미포함 기능은 아래와 별도 분석 문서에 명시합니다.

- 검사·리콜 버튼은 확인 후 인터넷의 자동차리콜센터(`car.go.kr`)와 한국교통안전공단 사이버검사소(`cyberts.kr`)를 브라우저로 엽니다. 차량별 리콜·검사 정보를 자동 수집하거나 번호를 전송하지 않습니다. 실제 결과·대상 여부는 공식 사이트에서 직접 확인하세요.
  검사소는 접속 환경에 따라 보안 확인 페이지를 표시할 수 있습니다. 자동 접속 검사에서는 이 보안 페이지의 반복 이동으로 내용을 확인하지 못했으며, 매장 PC의 브라우저에서 직접 확인해야 합니다.

- `자동분류 규칙`: 주유·병원·통신·식비·카페·교통·급여 등 기본 키워드 추천과 사용자가 만든 규칙을 지원합니다. 새 거래의 내용이나 붙여넣은 문자에 대해 로컬에서 추천합니다. 우선순위·수입/지출·키워드·분류·사용 여부를 수정할 수 있으며 직접 고친 분류는 자동으로 덮어쓰지 않습니다. 키워드 기반 추천이므로 확정 전 확인해야 하며 외부 AI나 은행 정보를 조회하지 않습니다.
- 달력은 기록된 일별 지출과 무지출 표시를 제공합니다. 큰 금액은 ‘만’ 단위로 줄여 표시하며 날짜에 커서를 대면 원래 금액을 볼 수 있습니다. 기록 누락이 있는 날도 무지출로 보일 수 있으므로 실제 통장·카드 명세와 대조하세요.
- 이번 달 예산 진행 바는 `오늘까지 전체 지출 ÷ 이번 달 총예산 × 100`으로 계산합니다. 모든 통장을 포함하고 이체·시작 잔액·미래 날짜 지출은 제외합니다. 80%부터 주의색, 100%부터 초과색이며 바는 100%에서 멈추되 실제 초과율과 금액은 숫자로 표시합니다. 예산 0원은 미설정으로 처리합니다. 지난달 전체 지출과 전월 같은 일수까지의 증감도 따로 보여주며 이전 금액이 0원이면 증감률을 계산하지 않습니다. 이번 달 가장 많이 쓴 분류의 금액·비중을 강조합니다. 이 요약은 조회 필터와 무관한 이번 달 전체 기록 기준입니다.

- `사진·문서 첨부`: 가계부 거래·차량 비용/비용 없는 기록·일기를 먼저 저장하고 선택한 뒤 첨부합니다. 사진·PDF·한글·오피스 문서 등을 파일당 10MB, 기록당 20개, 사용자당 200MB까지 장부 안에 암호화 보관합니다. 원본 파일을 옮겨도 첨부 복사본은 남으며 백업·복원에도 포함됩니다. 파일로 꺼낼 때는 확인창을 표시합니다. 꺼낸 파일에는 개인 암호가 적용되지 않으며 자동 실행하지 않습니다. 첨부파일은 악성코드 검사를 대신하지 않습니다.
- `기념일·알림`: 첫화면과 같은 개인 일정을 가계부에서도 조회·등록합니다. 양력/한국 음력·매년 반복·미리 알림을 지원합니다. ‘문자 초안’은 내용을 편집해 클립보드로 복사하는 기능이며 실제 문자 발송·요금은 없습니다. 일정은 첫화면에서 보이는 로그인 보호 자료이며 가계부 별도 암호로 암호화되지 않습니다. 비밀 금융정보를 일정에 적지 마세요.

### 새로 보강한 재무·계획 메뉴

가계부의 `재무·계획` 탭에서 아이콘이 있는 하위 탭을 선택하세요. 탭이 많으면 오른쪽 화살표로 옆으로 이동할 수 있습니다. 창을 최대화하거나 스크롤해 모든 입력과 버튼을 볼 수 있습니다.

- `재무상태표`: 통장 잔액 + 수동 자산 평가, 부채, 순자산. 예·적금/투자 통장은 묶인 자산으로, 마이너스 통장은 부채로 구분합니다. 이미 통장에 있는 금액을 수동 자산/부채에 다시 넣지 마세요. 수동 평가는 최신 입력값이며 과거 시세를 재현하지 않습니다.
- `목돈 목표`: 목표일·금액·직접 모은 금액 또는 연결 통장으로 달성률·남은 금액·월 필요 저축을 확인합니다. 목표를 자산에 한 번 더 더하지 않습니다.
- `항목별 예산`: 원하는 월과 분류별 예산·실제 지출·남은 금액·사용률. 월 전체 예산은 따로 설정하며 분류 예산을 자동 합산해 덮어쓰지 않습니다.
- `월·연간 결산`: 1~12월 수입·지출·고정/변동비·수지 차액·예산 잔액. 이체·시작 잔액은 수입/지출에서 제외합니다.
- `생활비·현금흐름`: FP114 설명서의 필요생활비·순생활비를 참고해 교육/세금/저축 등을 구분합니다. 분류별 생활비 구분을 직접 변경할 수 있습니다.
- `미래 잔액 예상`: 오늘 통장 합계 + 다음 달부터 12개월의 예상 월 수입 − 활성 고정비. 현재 월 남은 기간·변동비·카드 청구·금리 등은 제외한 단순 시나리오로 실제 미래 잔액이 아닙니다. 거래나 송금을 자동 생성하지 않습니다.
- `맞춤 보고서`: 상단 기간·통장·분류·검색과 일자/통장/항목/거래처/소유자/태그/금액·빈도 Top 10을 조합합니다. 선택 묶음의 세부 거래 팝업·인쇄·엑셀과 조건 저장을 지원합니다. 태그별 묶음은 중복될 수 있으나 전체 수입/지출 합계는 한 번씩 집계합니다.
- `자주 쓰는 거래틀`: 내용·분류·금액·거래처를 저장하고 입력 창에 불러옵니다. 확인 후 저장해야 실제 거래가 기록됩니다.
- 거래내역을 오른쪽 클릭하면 수정·첨부·거래 나누기를 사용할 수 있습니다. 나누는 금액 합계가 원래 금액과 같아야 저장되며 첫 세부 거래에 기존 첨부를 유지합니다. 차량·고정비·이미 나눈 거래는 제외합니다.

계정 종류·소유자는 `통장 수정·보관`에서 설정합니다. 개인 별칭으로만 구분하며 주민등록번호나 금융 인증서·CVC·은행 비밀번호는 받지 않습니다. 모든 새 재무 계획·거래틀·보고서 설정은 개인 가계부 키로 암호화하고 백업에 포함합니다.

카드 대금/할부 시뮬레이터, 대출 원리금 자동 추적, 같은 계정 안의 독립 다중 프로필, 영수증 OCR은 아직 포함하지 않았습니다. 여러 로그인 계정의 개인 자료 분리는 이미 지원하지만 같은 기능으로 부르지 않습니다. 원본 가계부 PDF·Word 안내 62개에 대한 반영/미포함 범위와 공개 참고 주소는 `PERSONAL_GUIDE_ANALYSIS.md`에 정리했습니다.

### 일기장·차량·업무일지 추가 안내

- 일기장은 달력의 기록일 표시·태그·제목/본문/마음 검색·소중한 일기·작성 편수·감사/하루/건강/마음 기록 양식·집중 모드를 제공합니다. 양식은 기존 글을 덮어쓰지 않고 끝에 추가합니다. 저장 버튼으로 암호화 보관합니다. 사진/문서 첨부·선택 테마·자체 음악 기능도 유지합니다.
- 차량 리포트는 비용 종류 원형·월별 막대 차트와 구매 주유량·평균 구매 단가를 표시합니다. 차량 화면은 예정 미처리 건수와 날짜/주행거리 남은 양을 보여 줍니다. 만땅법 참고 연비와 실제 연비·공식 성능 판정은 다릅니다.
- 업무일지는 `업무·인수인계`, `일·주·요일 통계`, `물동량·생산성`으로 구성합니다. 등록정보 팝업에 예정/진행/완료/보류·고객사·근무일, 하역/적치/피킹/출고/리버스 작업, 작업자별 시간·시급·사용자 입력 잔업 배율, 보관 CAPA·현재량·적정율, 매출/비용·인수인계를 기록합니다. 실제 작업량과 계약 매출은 분리 입력하며 EA·BOX·PLT는 섞어 합산하지 않습니다. 통계는 예정·보류도 포함한 관리용 입력값이며 실제 급여·송장·회계를 확정하지 않습니다. 업무일지·첨부는 별도 암호화하지 않으며 현재 계정만 조회합니다. POS 재고·전표·가계부에 자동 전기하지 않습니다.
- `행운의 숫자`는 로그인 화면에서도 여는 독립 재미용 추첨기입니다. 한 개씩 또는 한 줄 6개 자동 추첨, 오른쪽 5줄 자동 채우기를 선택합니다. 줄 안의 번호는 1~45 중 중복 없이 뽑고 완성된 줄은 오름차순으로 표시합니다. 줄 사이에는 번호가 겹칠 수 있습니다. 새 추첨은 확인 후 모든 줄을 지우고, 번호 복사는 완성된 줄만 복사합니다. 실제 복권 구매·당첨 예측과 무관합니다. 참고 사진·출처 링크는 화면에 표시하지 않습니다.

판매관리는 PDF 이름의 취소내역·보류내역, 대·중·소분류 선택, 전일/전주/전월 날짜 전체 비교를 보강했습니다. 실시간 조회의 자동갱신을 30초/1분/2분/5분/끄기로 지정할 수 있습니다. 진행 중인 오늘과 과거 하루 전체를 비교하므로 같은 시간대 비교가 아닙니다. 다른 점포·카드 승인 서버의 매출은 가져오지 않습니다.

## 같은 네트워크 PC 공유 (선택)

기본값은 종전과 같은 단독 사용입니다. 상단 `PC 연결 · 공유`에서 프로그램으로 기준 PC를 고릅니다. 별도 서버 설치·장비나 인터넷은 필요 없지만 **기준 PC의 프로그램이 켜져 있어야** 연결 PC의 공유 업무가 가능합니다. SQLite 파일을 공유 폴더에 놓고 동시에 열지 마세요.

1. 기준 PC에 관리자 로그인 → `기준 PC` 선택 → ‘이 PC 주소 선택’ → ‘기준 PC 인증키 생성’. 연결 파일을 내보내고 설정 저장 후 재실행합니다. 고정 내부 IP를 권장합니다.
2. 다른 PC는 같은 버전 프로그램에서 `연결 PC`를 선택하고 `.poslan` 파일을 불러온 뒤 별도로 전달받은 연결 코드를 넣습니다. 기준 PC와 인증서 SHA256 지문이 같은지 확인하세요. 연결 파일에는 장부·개인키·연결 코드를 넣지 않습니다.
3. 선택한 사설 IPv4로만 수신하며 인증서/호스트를 검증하는 TLS 연결을 사용합니다. 공용 인터넷 주소·DNS·0.0.0.0 바인딩은 지원하지 않습니다. Windows 방화벽은 신뢰하는 개인 네트워크에서만 허용하고 공유기 포트 개방은 하지 마세요. 인증키·코드는 현재 Windows 사용자 DPAPI로 저장합니다.
4. 업무 목록은 약 3초마다 변경을 확인해 자동 갱신합니다. 팝업이나 편집 중에는 갱신을 미뤄 입력을 보호합니다. 상품/작성 중 전표가 다른 PC에서 변경되면 덮어쓰지 말고 최신 자료를 다시 열어야 합니다. 다른 기초자료는 동시에 같은 항목을 편집하지 마세요.
5. 끊긴 저장 요청은 암호화된 요청 번호로 재시도해 같은 요청을 두 번 반영하지 않습니다. 다른 거래를 입력하기 전 `미확인 저장 결과 확인`에서 결과를 확인하거나 아직 반영되지 않은 요청을 취소 처리하세요. 기준 PC 복원 전 요청은 자동으로 다시 저장하지 않습니다. 연결이 끊기면 공유 입력은 중단되며 오프라인 입력을 쌓아 나중에 합치는 방식은 제공하지 않습니다.
6. 직원/권한·매장 설정·업무 백업/복원은 기준 PC에서 관리합니다. 복원 전에는 단독 사용으로 바꾸고 종료·재실행하여 공유를 멈추세요. 모든 PC의 작업을 중단하고 복원 후 다시 로그인해야 합니다.
7. 일기장·가계부·건강·개인 일정·업무일지·첨부는 각 PC에 남습니다. 연결 PC의 개인 저장소는 `data-v2/personal/<기준PC 인증서 식별값>/personal.db`, 백업은 그 아래 `backups`입니다. 종료 자동 백업과 최신 15개 주간 정리를 적용합니다. 관리자는 연결 메뉴의 `이 연결 PC의 개인 자료 백업·복원`에서 목록/파일 선택 복원을 할 수 있습니다. 기준 PC 업무 백업을 여기 복원할 수는 없습니다. 연결 PC의 복구 이메일용 SMTP도 그 PC에 별도로 설정합니다.

먼저 가상 자료로 두 PC의 연결·자동 갱신·끄기/재접속을 시험한 뒤 사용하세요. 로컬 자동 검사는 실제 매장 공유기·방화벽·동시 사용 부하 시험을 대신하지 않습니다. 새 기준 PC 인증키를 만들면 연결 PC의 이전 개인 저장소가 별도 프로필로 남으므로 먼저 개인 백업을 보관하세요.

## 기존 미리보기에서 계속 제공하는 기능

새 폴더에 압축을 풀고 먼저 `체험 실행.bat`으로 화면을 확인하세요. 기존 프로그램이나 실자료 폴더에 덮어쓰지 마세요. 2.2 이하 독립판 장부는 처음 열 때 보호 백업 후 금액을 0.01원 단위로 업그레이드합니다. 업그레이드한 장부는 이전 EXE로 다시 열 수 없습니다. 기존 폴더와 백업을 따로 보관하세요.

- 로그인 직후와 첫화면 이동 시 왼쪽은 매입/발주관리만 펼칩니다. 기초·판매·레포트·회원 메뉴의 오프라인 하위 기능을 연결했습니다.
- 첫화면에는 PC 시각, 월 달력, 권한별 날짜 매입·판매 합계, 계정별 일정·메모·알림이 있습니다. 알림은 실행 중에 표시되며 지난 알림은 다음 실행 때 한 번 표시합니다.
- 로그인 왼쪽의 매장·가계부·일기장 아이콘을 선택하고 로그인하면 해당 메뉴로 바로 이동합니다. 개인 암호를 우회하지 않습니다. 로그인 후에도 왼쪽 나의 기록에서 열 수 있습니다. 첫 admin 로그인에는 8~128자의 새 로그인 암호 설정이 필수입니다.
- 생일·결혼기념일·제사·기념일·행사는 양력/음력과 해마다 반복, 알림 시각·며칠 전 알림·설명을 지정할 수 있습니다. 실제 경과 일수와 나이/주년을 표시하며 큰 강조 팝업으로 알립니다. 닫힌 프로그램을 자동 실행하거나 Windows 종료 중 알리는 기능은 없습니다.
- 한국 음력은 오프라인 1900~2050년 범위입니다. 윤달 없는 해의 평달 대체를 선택할 수 있습니다. 음력 30일이 없는 해는 29일, 양력 2/29는 평년 2/28로 적용합니다. 제사 날짜는 전날로 자동 변경하지 않습니다. 완료는 반복 전체를 중지하며 해제하면 다시 알립니다.
- 날씨와 인터넷 한국 시각은 기본 꺼짐입니다. 첫화면의 지역·표시 설정에서 직접 지역을 선택하고 켜세요. GPS·IP 자동 위치 조회 없이 국내 기상청 격자 예보를 사용합니다. TimeAPI 시각은 참고 정보입니다. 연결 실패 시 PC 시각과 오프라인 업무를 계속 사용합니다.
- 상품분류는 대·중·소 트리입니다. 미선택 새 상품의 기본 분류는 `미분류 / 미분류 / 신상품`입니다. 기존 상품 분류는 임의로 변경하지 않습니다. 공급사 정보·결제유형·일반그룹, 상품장·확장단위의 우클릭 메뉴와 변경로그를 추가했습니다.
- 새 중량상품은 g 기본단위와 100g당 단가를 사용할 수 있습니다. 예: 10,100g × 1,650원 ÷ 100 = 166,650원. 기존 kg 상품·확장단위는 기존 환산 기준을 보존하며 kg 상품의 전표에서 g 환산 입력도 선택할 수 있습니다.
- 매입·단가·결제·잔액은 소수점 두 자리로 보존합니다. 환경설정에서 원 단위 반올림을 선택할 수도 있으며 각 전표에 계산 방식을 보존합니다. 확정된 과거 전표를 설정 변경으로 재계산하지 않습니다.
- 매입전표를 유지한 채 별도 상품장을 열어 새 상품을 저장하고 작성 중인 전표에 즉시 추가할 수 있습니다. 상품 저장이 전표 자동 확정을 뜻하지는 않습니다.
- 견적서·거래명세서·회원 (세금)계산서 참고자료는 실제 재고·판매·결제에 다시 반영하지 않는 출력 문서입니다. 후자의 자료는 전자세금계산서 발행·세무 신고용 법정 서식이 아닙니다.

## 나의 기록 · 일기장·가계부·업무일지

왼쪽 업무 트리 아래의 별도 테두리에 모아 두되 자료와 암호는 따로 관리합니다. 계정별 자료이며 다른 계정의 자료를 앱에서 조회하지 않습니다.

- 보안 일기장: 별도 8~128자 암호, 제목·본문·날짜·기분을 AES-256-GCM으로 암호화합니다. 일반 닫기는 같은 로그인 동안 잠금 해제를 유지하며 음악을 멈춥니다. 자리 비움 시 ‘잠그고 닫기’를 사용하세요. 일기장 인쇄·엑셀 내보내기는 제공하지 않습니다.
- 가계부: 수입·지출·분류·메모, 기간/분류/검색별 합계·이월·잔액, 인쇄·PDF·엑셀을 제공합니다. 매장 전표나 재고·결제를 변경하지 않습니다. 별도 암호는 선택할 수 있으나 개인 금융정보에는 암호 사용을 권장합니다. 암호 미사용은 별도의 암호 보호를 제공하지 않습니다.
- 가계부와 일기장은 각각 별도 팝업창입니다. 크림·장미·초록·라벤더·밤의 5가지 테마를 창별·계정별로 선택합니다. 작은 열기/닫기 효과음은 켜기/끄기가 가능하며 배경 음악과 독립입니다. 가계부 달력에서 날짜별 수입·지출·메모 표시를 확인하고, 금액 없이 자유 메모만 암호화 저장할 수도 있습니다.
- 각 개인 창의 `건강·병원 기록`: 대상 이름별 키(cm)·몸무게(kg)·생년월일·성장 나이·메모, 식사·운동·다이어트, 진료·치료일, 병원 예약, 약국 구매와 금액을 기록합니다. 내용은 해당 개인 창의 데이터키로 암호화하며 두 창의 건강 기록도 서로 분리합니다. 가계부 암호를 끄면 이 기록에도 추가 암호 보호가 없습니다. 의료 판단 기능이 아닙니다.
- 건강 확장: 체중/수분/참고 칼로리 목표, 식사별 음식·섭취 kcal·단백질/탄수화물/지방/당류(g)·나트륨(mg), 요가/운동 종류·분·세트·횟수·거리·수동 소모량, 수분(ml), 혈압·맥박·혈당·허리둘레를 직접 기록합니다. 주간/월간/직접 기간 리포트와 개인별 체중 그래프를 제공합니다. 식단 계획표와 요일별 운동 루틴은 실제 섭취·운동 합계에 넣지 않습니다. 외부 영양소 DB·사진 칼로리 판독·웨어러블 동기화는 없습니다.
- 수면은 기록일에 잠든 시각과 깬 시각을 입력합니다. 종료 시각이 빠르면 다음 날로 계산하며, 같은 시각은 거부합니다. 수면 시간·주관적 만족도와 스트레스(0~10)를 기록하고 조용한 명상 타이머로 실제 경과 시간을 남길 수 있습니다. 과학적 수면 진단·정신건강 평가·치료 기능은 아닙니다.
- 비타민/영양제는 사용자가 입력한 제품·복용 메모·시각(하루 최대 6회)·요일·종료일로 확인 팝업을 설정합니다. 가계부/일기장 또는 건강 창을 잠금 해제해 둔 동안, 당일 도래한 시각만 한 번 알립니다. 잠금·종료 중에는 복용 알림을 보내지 않으며 지난 날짜의 놓친 복용을 권하지 않습니다. 복용 완료를 자동 처리하지 않습니다. 의료진·제품 안내를 따르고 실제 복용 여부와 중복 복용을 확인하세요.
- 바디 체크는 가슴·허리·엉덩이·팔·허벅지 치수와 사진·문서를 저장할 수 있습니다. 기록 저장·선택 후 ‘사진·문서 첨부’를 사용하세요. 첨부도 해당 개인 암호화·백업에 포함되며 파일로 꺼내면 별도 암호가 적용되지 않습니다. 체형 판정·신체 사진 분석은 하지 않습니다.
- 병원 예약 알림을 켜면 날짜·시각과 일반적인 ‘개인 일정’ 문구만 첫화면에 저장합니다. 병원·치료명·설명은 개인 창을 열어 확인합니다. 진료·약국 금액은 참고 기록으로 가계부 잔액·매장 전표에 자동 합산하지 않습니다. 미완성 건강 편집은 장시간 미사용 잠금 시 보호를 위해 지울 수 있으니 먼저 저장하세요.
- 업무일지: 계정별 날짜·제목·업무 내용을 기록·검색·수정·삭제·출력합니다. 일기장과 달리 별도 암호화하지 않습니다.
- 배경음악: 녹음 권리 문제 없는 자체 생성 잔잔한 앰비언트입니다. 달력 날짜 1~31일과 계절에 따라 다른 변주를 사용하며 기본 음량은 6%, 끄기·조절이 가능합니다. 음원은 오프라인에서 음악 캐시에 생성합니다. 유명 클래식 녹음은 아직 포함하지 않았습니다. 실제 스피커에서의 청취 품질은 직접 확인해 주세요.

## 이메일 전용 암호 복구

문자 인증·SMS·자동 관리자 복구·숨겨진 만능 암호는 없습니다. 메일 발송 계정도 프로그램에 내장하지 않습니다.

1. 관리자가 `기초관리 → 환경설정·백업 → 이메일 발송 설정`에서 SMTP 서버·보안 연결·발송 계정·앱 비밀번호를 입력합니다. 암호화 연결만 지원합니다. 서비스의 SMTP·앱 비밀번호 정책을 확인하세요.
2. 발송 비밀번호는 현재 Windows 사용자 DPAPI로 암호화 저장합니다. 다른 PC/Windows 계정에서 SMTP 설정을 다시 입력해야 합니다. 비밀번호를 채팅으로 보내거나 소스에 넣지 마세요.
3. 각 사용자가 상단 `복구 이메일`에서 주소를 입력하고 자신의 로그인 암호를 확인합니다. 그 주소로 받은 8자리 코드를 확인해야 등록됩니다. 이후 주소 변경도 현재 로그인 암호와 새 주소 인증이 필요하며, 개인 이메일 복구는 새 주소에서 다시 등록해야 합니다.
4. 로그인 창의 `로그인 암호 찾기 · 이메일 인증`에서 코드를 요청하고 새 암호를 설정합니다. 기존 암호를 메일로 보내지 않으며 인증 전에는 바꾸지 않습니다. 10분 유효·1회 사용·5회 오입력 무효·분당 1회/시간당 5회 요청 제한이 있습니다.
5. 일기장·가계부는 암호를 잊기 전에 각각 이메일 복구를 등록해야 합니다. 현재 개인 암호를 확인한 뒤 보내는 **최초 복구 메일의 복구키**를 보관하세요. 나중에 새 인증번호와 이 복구키를 함께 입력하면 내용을 보존하고 개인 암호를 재설정합니다. 복구키를 관리자에게 자동 보관하지 않습니다. 현재 개인 암호로 재발급하고 메일 인증을 완료하면 이전 키가 무효가 됩니다.
6. 개인 암호와 최초 메일의 복구키를 모두 잃거나, 사전 복구 등록을 하지 않았다면 암호화 내용을 복구할 수 없습니다. 이메일 주소만 알고 있는 것으로 복구되지 않습니다.

SMTP 처리는 모의 발송으로 자동 검증합니다. 실제 발송 계정·수신함 검증은 사용자가 Windows에서 설정한 후 확인해야 합니다. 전송 실패·만료·틀린 코드·잘못된 복구키는 기존 암호와 개인 내용을 변경하지 않습니다. 장부 자체는 이메일 미설정·오프라인 상태에서도 사용할 수 있습니다. 이 기능은 신뢰할 수 있는 개인 Windows 계정을 전제로 하며 OS 관리자·악성코드로부터 모든 실행 중 메모리를 보호하는 기능은 아닙니다.

프로그램 복사 추적·관리자 자동 통보·원격 사용 중지·온라인 라이선스 서버는 이 미리보기에 없습니다. 다른 PC 실행 통보나 원격 정지는 사용자 동의와 별도 인증 서비스 설계가 필요한 기능입니다.

## Windows 실행

1. `SY-POS-v2.4.0rc12-Windows-x64-portable.zip`을 다운로드합니다. 압축파일 이름에 버전이 표시됩니다.
2. 바탕화면이나 문서 아래의 쓰기 가능한 새 폴더에 **전체 압축을 풉니다**. 압축 파일 안에서 직접 실행하거나 EXE만 다른 곳으로 옮기지 마세요.
3. `SY-POS.exe`를 실행합니다. Python을 설치할 필요가 없습니다.
4. 새 장부의 초기 로그인은 **아이디 `admin` / 비밀번호 `1234`**입니다. 최초 로그인 화면에서 8~128자의 본인 암호를 두 번 입력해야 진입합니다. 공개 초기 암호를 계속 사용할 수 없습니다. 이후에는 설정한 암호로 로그인합니다. 기존 계정이나 변경한 비밀번호는 초기값으로 덮어쓰지 않습니다. 관리자 모드에서 사용자별 접근권한·매장 설정·백업을 관리합니다.
5. 이후 같은 폴더의 EXE를 실행하면 기존 자료가 유지됩니다. 실자료는 EXE 옆 `data-v2/seoyoung-standalone-v2.db`에 저장됩니다.

Windows 10/11 x64용입니다. 프로그램과 데이터 폴더를 함께 보관하세요. 기존 프로그램 폴더에 덮어쓰지 마세요. PC를 바꾸려면 프로그램을 종료한 뒤 폴더 전체를 복사하거나 관리자 설정의 DB 백업을 사용하세요. 다른 프로그램의 DB는 열지 않습니다. 실행 중인 장부를 USB 드라이브에서 분리하거나 네트워크·동기화 드라이브에서 동시에 열지 마세요. 단독 운영이 기본이며 여러 PC는 위의 선택형 연결 기능만 사용하세요.

화면·PDF·라벨의 한글 표시를 위해 OFL 라이선스의 Noto Sans KR 글꼴을 함께 제공합니다. Windows 언어팩이나 온라인 글꼴 다운로드가 필요하지 않습니다. ZIP의 내부 파일도 함께 압축 해제해야 합니다.

`체험 실행.bat`이 있는 배포본에서는 별도 체험 자료로 화면과 기능을 확인할 수 있습니다. 체험 계정은 `demo` / `Standalone-Demo-2026!`이며 실자료 로그인에 사용할 수 없습니다. 체험 실행은 실제 장부와 다른 파일을 사용합니다.

## 업무 순서

- `기초관리 → 상품 분류`에서 대·중·소분류를 먼저 만듭니다. 트리에서 마우스 오른쪽 버튼으로 추가·수정·삭제·유효/무효·하위분류 표시를 선택합니다. 사용 중인 분류나 하위분류가 있는 항목은 삭제되지 않습니다.
- 공급사를 등록하고 상품장에 상품을 만듭니다. 상품코드는 `P00001`부터 저장 시 순차 생성하며 중복되거나 삭제한 번호를 재사용하지 않습니다. 기본단위(예: g), 가격 기준(1단위/100g), 매입가·판매가, 원산지, 바코드, 재고 관리 여부를 정합니다. 금액은 소수 두 자리, 수량은 소수 셋째 자리까지 지원합니다. 분류는 등록된 목록에서 선택하거나 검색합니다.
- 상품 등록창 왼쪽 위에서 `유효 / 무효 / 퇴출대상`을 정합니다. 퇴출대상은 재고 소진을 위해 거래 가능하며, 무효는 신규 거래에서 제외합니다. 상품코드·기본/확장 바코드·상품명·규격으로 검색할 수 있습니다.
- PDF와 같은 `매입/발주관리 → 매입전표`에서 기간·공급사·유형(전체/매입/반품)을 선택합니다. 오른쪽 `매입등록` → 공급사 선택 → 상품·수량·매입가 → `저장` 순서입니다. F3 공급사, F5 상품검색, F6 선택행 수량 편집, F7 선택행 삭제, F9 새 상품등록을 지원합니다.
- 전표의 `상품 검색(F5)`은 선택 공급사 상품을 먼저 보여줍니다. `선택 공급사만`을 해제하면 전체 공급사와 미지정 상품도 보입니다. 한 품목은 더블클릭, 여러 품목은 체크 후 적용합니다. 규격·바코드·환산량·총수량·금액·분류·공급사를 넓은 표에서 확인합니다. 열 너비를 조절하거나 가로로 이동할 수 있습니다.
- 바코드 스캔이나 상품 선택은 입력만 합니다. 매입의 `전표 적용`(Alt+A)은 초안으로 저장하고 창을 유지하며 재고·원장을 변경하지 않습니다. `저장`(Alt+S)하면 확인 후 거래·재고·결제가 함께 반영됩니다. 매출은 `초안 저장`/`전표 확정`을 사용합니다. `미지급잔액`은 이 전표의 잔액이며 미결제·부분결제·결제완료를 표시합니다. 초안은 예상값, 확정 전표는 이후 결제·반품을 반영한 실제 잔액입니다. 거래처 전체 잔액은 원장에서 확인합니다.
- PDF처럼 같은 새 매입전표 상단의 `반품`을 체크하거나 목록 아래 `반품등록`을 누릅니다. 원매입전표 선택 → 반품 수량 입력 → 저장 순서입니다. 원래 단가와 남은 반품 가능량으로 계산해 재고와 외상을 차감하고 실제 환급을 구분합니다. PDF와 달리 원전표 없는 임의 반품이나 확정 전표의 매입/반품 종류 덮어쓰기는 허용하지 않습니다.
- 판매 등록에서도 같은 방법으로 상품을 추가합니다. 비회원 외상은 판매처 원장에서 추가 결제합니다. 회원 매출은 현금/계좌이체+포인트로 완전 정산해야 합니다.
- 확정 거래는 직접 금액을 덮어쓰지 않습니다. 가능한 경우 사유를 넣어 취소하고 다시 등록하거나, 원전표·원행에 연결된 부분 반품을 등록합니다. 취소는 후속 재고·반품·포인트·마감 조건에 따라 제한됩니다.
- 실사는 장부수량을 조회해 초안 저장 후 적용합니다. 초안 이후 재고·원가·이동 이력이 달라지면 적용이 차단되므로 다시 조회해야 합니다.
- 일·월·상품·분류·공급사·회원 보고서, 거래처 원장, 사용자별 현금 마감, 월 재고 마감을 사용할 수 있습니다. 월 마감 이후 해당 기간 거래·재고 변경은 차단됩니다.

## 사진을 참고한 화면

상단 업무 메뉴·바로가기, 왼쪽 업무 트리, 넓은 조회표, 날짜·공급사·상품 필터를 배치했습니다. 상품 등록은 상품정보·매입·판매·재고·변경기록·확장단위 탭으로 구성합니다. 원본 프로그램의 로고·아이콘·이미지는 사용하지 않고 밝은 색의 새 UI로 설계했습니다. 표는 정렬·열 너비 변경과 천 단위 금액 표시를 지원합니다.

## 결제관리 (공급사 지급)

`매입/발주관리 → 결제관리`를 사용합니다. PDF p.146~153의 외상매입내역조회 → 월별거래내역조회 → 매입전표 상세와 결제내역조회 흐름을 별도 서버 없이 앱 안에서 처리합니다.

1. 기간·전체/선택 공급사·이름/코드로 조회합니다. `기간 내 매입 있는 공급사만`을 해제하면 매입이 없는 공급사도 표시합니다. 기간 전 이월, 매입·반품·순지급, 기간말과 현재 잔액을 구분합니다.
2. 공급사를 더블클릭하면 해당 기간의 거래·지급 내역을 봅니다. 매입 행을 더블클릭하면 원전표 상품 상세가 열립니다.
3. `결제 처리`에서 실제 지급일, 금액, 현금/계좌이체, 메모를 입력합니다. 선택일과 현재의 결제 가능한 잔액 이내에서 **초기 외상 → 오래된 매입전표 순서**로 배분합니다. 부분결제도 가능하며 등록 전 배분표를 확인합니다. 결제일보다 늦은 전표에는 배분하지 않습니다.
4. 결제 내역 탭에서 전체/선택 공급사의 이력과 묶음 결제 배분을 봅니다. 당일 결제는 사유 확인 후 전체 취소·재등록할 수 있습니다. 지난 날짜, 현금/월재고 마감, 이미 지급액에 연결된 환불 등으로 취소가 제한될 수 있습니다. 묶음의 일부 전표 결제만 임의 취소하지 않습니다.
5. 활성 탭의 조회 결과를 인쇄·엑셀로 저장합니다. 은행에 실제 송금하거나 카드를 승인하지 않으며, 사용자가 지급한 금액을 장부에 기록하는 기능입니다. 반품 환급은 원전표의 반품·환불 절차를 사용합니다. 현금마감은 종전과 같이 매출 수금·고객 환불 기준이며 공급사 지급은 별도 결제관리 원장에서 확인합니다.

## 관리자 권한 설정

모든 업무 메뉴의 `첫화면` 버튼 또는 Ctrl+Home으로 업무 첫화면에 돌아갑니다. 편집 팝업에도 첫화면 버튼이 있습니다. 저장하지 않은 변경이 있으면 `저장 / 저장하지 않음 / 돌아가기`를 확인하며, 이때 전표와 실사는 확정하지 않고 초안으로 저장합니다. 조회 필터 변경에는 저장 확인을 표시하지 않습니다. 왼쪽 메뉴·상단 메뉴·바로가기·첫화면 업무 버튼에 약 0.7초 커서를 머무르면 짧은 한글 설명이 뜹니다.

`관리자 모드 → 권한 설정`에서 직원을 선택하고 메뉴별 **조회·접근 / 등록 / 수정·편집 / 삭제·취소**를 체크해 저장합니다. 조회만 체크하면 읽기 전용이며, 관리자 계정은 제한하지 않습니다. 일반 직원은 이 메뉴에 접근하거나 자신의 권한을 변경할 수 없습니다. 사용자 관리의 `메뉴별 권한 설정` 버튼으로 선택 직원을 바로 열 수도 있습니다.

권한은 실제 저장 엔진에서 재확인합니다. 이미 열린 창이라도 회수된 권한으로 저장·삭제할 수 없습니다. 접근권한을 회수하면 다음 조회·출력에서 차단합니다. 종전 업무영역 권한은 유지하며 새 설정 화면에서 세부 제한을 지정합니다. 사용하지 않는 작업 열은 비활성입니다. 결제의 금액 정정은 취소 후 재등록 방식으로 삭제/취소·등록 권한이 모두 필요하고, 전표 반품도 삭제/취소 권한이 필요합니다. 자세한 예는 `PERMISSIONS_GUIDE.md`를 참고하세요.

## USB 바코드 리더기

키보드처럼 입력되는 **USB HID 방식**을 지원합니다. 리더기의 종료 문자를 Enter 또는 Tab으로 설정하고 F8 또는 바코드 입력칸을 선택한 뒤 스캔하세요. 바코드는 문자열로 처리해 앞자리 0을 보존합니다. 스캔 완료만으로 저장·확정되지 않습니다. 기본 바코드와 확장단위(예: kg 상품의 500g 팩) 바코드를 구분하고 같은 기본 재고로 환산합니다. 미등록 바코드는 안내하며 임의 상품을 자동 생성하지 않습니다. 전용 시리얼·네트워크 장치 프로토콜은 포함하지 않습니다.

## 인쇄·라벨·엑셀

- 조회표와 거래 내역은 `인쇄`에서 미리보기 후 Windows에 설치된 프린터로 출력합니다. PDF 프린터도 사용할 수 있습니다. 엑셀은 `.xlsx`로 저장하며 금액·수량을 숫자로 내보냅니다.
- 상품장에서 상품을 선택하거나 `라벨 출력` 메뉴를 열어 상품·확장단위의 바코드 라벨을 만듭니다. 상품명·가격·원산지·바코드가 출력됩니다.
- 라벨 기본 크기는 **60×40mm**입니다. 가로 30~150mm, 세로 20~150mm, 위치 보정·매수를 지정할 수 있습니다. 프린터 드라이버에도 실제 용지와 같은 사용자 지정 크기를 설정하세요. 크기가 다른 상태로 인쇄하면 차단됩니다.
- Code128 또는 유효한 EAN13을 사용합니다. 잘못된 EAN 체크 숫자는 임의 수정하지 않습니다. 앞자리 0을 보존해야 하는 코드는 자동 모드에서 Code128로 출력합니다. 용지에 비해 너무 긴 바코드는 출력하지 않습니다.
- 프린터 모델을 정하면 제조사 Windows 드라이버를 설치하세요. 실제 기기에서는 먼저 **라벨 1장**으로 크기·위치·스캔 여부를 시험해야 합니다. 클라우드에서는 물리 프린터와 리더기의 동작을 직접 확인할 수 없습니다.

## 자료 보호와 주의

### 백업과 복원

- 관리자 `매장 설정 · 백업 → 자동 백업 설정`에서 자동/수동, 매일/요일 선택/1~365일 간격과 실행 시간을 정합니다. `설정 저장` 후 적용됩니다. 기본은 매일 20:00 자동 백업과 종료 백업 켜짐입니다. 프로그램 실행 중 약 1분마다 확인하고, 꺼져 있어 놓친 일정은 다음 실행 때 한 번 백업합니다. 별도 Windows 예약 작업·서버·인터넷은 사용하지 않으며 프로그램이 꺼진 동안 실행되지는 않습니다.
- `프로그램 종료 시 자동 백업`은 일정의 수동/자동 선택과 별개입니다. 작업 저장 확인을 마친 뒤 최신 자료를 백업합니다. 직원이 종료해도 고정 전용 폴더로 백업하며 설정 변경·복원 권한은 주지 않습니다. 실패하면 백업 없이 종료할지 확인합니다. 강제 종료·정전에는 종료 백업을 보장할 수 없습니다.
- 관리자 `매장 설정 · 백업 → 지금 백업`을 누르면 `data-v2/backups` 폴더가 자동 생성되고 날짜가 붙은 `.db` 파일이 저장됩니다. 체험 백업은 그 아래 `demo` 폴더로 분리합니다. 백업 목록은 최신순이며 생성일시·파일명·종류·크기를 확인할 수 있습니다.
- 목록에서 파일을 선택해 `선택한 백업 적용`을 누르거나 `다른 폴더 백업 선택`으로 외부 백업을 엽니다. 짧은 주의창과 현재 관리자 비밀번호 확인 후 적용합니다. **현재 자료가 선택한 백업 시점 자료로 교체됩니다.** 거래·상품·계정·설정을 포함하므로 복원 후에는 백업에 있던 계정으로 로그인합니다.
- 적용 직전에 현재 자료의 `복원전-자동백업`을 남깁니다. 파일 형식·버전·구조·무결성·관리자 계정을 검사하고, 손상·변조·다른 앱·사용 중인 파일은 거부합니다. 적용이 끝나면 프로그램이 종료되므로 EXE를 다시 실행하세요. 독립판 2.0.0/2.0.1 백업도 지원합니다. 구형 서영 POS 1~8차나 투게더 DB는 가져오지 않습니다.
- 자동 정리는 **7일에 한 번**, 이 프로그램이 만든 백업 중 **가장 최근 15개를 반드시 남기고** 이전 파일만 삭제합니다. 첫 실행은 기준일만 기록하며, 다음 7일이 지난 후 프로그램 실행 중 정리하고 삭제 수를 알림창으로 보여줍니다. 프로그램이 꺼져 있었다면 다음 실행 때 점검합니다. 다른 이름의 외부 파일은 자동 삭제하지 않습니다. 정리일 전에는 일시적으로 15개를 넘을 수 있습니다.
- 자동 정리로 지운 파일은 프로그램에서 되살릴 수 없습니다. 장기 보관할 백업은 외장 저장장치 등 **별도 폴더**로 복사하세요. 같은 PC의 백업 폴더만으로 디스크 고장에 대비할 수는 없습니다. 백업 파일은 암호화되지 않습니다.
- 2.4.0rc12로 연 장부를 구버전 EXE로 다시 열지 마세요. 독립판 2.0.0~2.4.0rc7 백업을 불러올 수 있습니다. 업데이트 전 원래 폴더 전체를 복사해 보관하고, 새 배포 폴더에서 백업을 선택해 복원하는 방법을 권장합니다.

계정별 접근 권한과 관리자 전용 설정을 분리하고, 비밀번호는 개별 salt가 있는 scrypt 해시로 저장합니다. 현재 로그인 계정 삭제·마지막 활성 관리자 제거를 차단합니다. 단, SQLite 파일 전체는 암호화하지 않으므로 Windows 계정·디스크 접근 권한과 정기 백업이 필요합니다. 계정 비밀번호를 잊었을 때 사용할 백도어는 없습니다.

재고원가는 **등록순 이동평균**입니다. 과거 날짜로 거래를 입력해도 이후 원가를 자동 재계산하지 않습니다. 보고서 분류는 현재 상품 분류 기준이며 거래 금액·상품명·수수료율 등은 저장 시점 기준입니다. 서로 다른 단위의 수량을 합산하지 않습니다. 공급사 수수료 보고서는 로컬 정산 자료이며 은행 송금·전자 세금 신고가 아닙니다. 이 프로그램의 보고서가 세무 신고의 정확성을 보증하지는 않습니다.

카드 승인/VAN·현금영수증 승인·센터 연결·온라인 상품 수신·SMS·원격지원·자동업데이트는 포함하지 않습니다. 종이 매뉴얼의 모든 기능을 완전히 복제한 제품은 아니며, 기능 대응과 미구현 범위는 `MANUAL_ANALYSIS.md`를 확인하세요.

## 소스 실행·검증

이 디렉터리는 기존 프로그램과 분리된 프로젝트입니다.

```bash
cd standalone
uv sync --frozen --extra dev
uv run --frozen --extra dev pytest -q
QT_QPA_PLATFORM=offscreen uv run --frozen --extra dev python -m pos2 --smoke-test
uv run --frozen python -m pos2
```

Windows PowerShell에서는 `$env:QT_QPA_PLATFORM = 'windows'`로 실제 Windows Qt 플랫폼을 사용해 검증합니다. Linux 클라우드 검증에는 `offscreen`을 사용합니다. Windows에서 `python build_portable.py`로 네이티브 EXE를 만듭니다. Linux 빌드는 Windows 실행 파일로 제공하지 않습니다.
