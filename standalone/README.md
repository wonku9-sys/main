# 서영 POS 독립판 2.0.1

PDF 사용설명서의 오프라인 업무 절차를 분석해 새 패키지 `pos2`와 새 SQLite 데이터베이스로 만든 Windows 매장 관리 프로그램입니다. 기존 서영 POS 프로그램·화면 클래스·업무 DB를 가져오거나 변환하지 않습니다. 인터넷, 웹브라우저, 별도 서버, GitHub 로그인 없이 실행합니다.

## Windows 실행

1. `SeoyoungPOS-Standalone-Windows-x64-portable.zip`을 다운로드합니다.
2. 바탕화면이나 문서 아래의 쓰기 가능한 새 폴더에 **전체 압축을 풉니다**. 압축 파일 안에서 직접 실행하거나 EXE만 다른 곳으로 옮기지 마세요.
3. `SeoyoungPOS-Standalone.exe`를 실행합니다. Python을 설치할 필요가 없습니다.
4. 처음에는 관리자 코드·이름·비밀번호를 직접 만듭니다. 비밀번호는 8~128자이며 기본 관리자 비밀번호는 없습니다.
5. 이후 같은 폴더의 EXE를 실행하면 기존 자료가 유지됩니다. 실자료는 EXE 옆 `data-v2/seoyoung-standalone-v2.db`에 저장됩니다.

Windows 10/11 x64용입니다. 프로그램과 데이터 폴더를 함께 보관하세요. 기존 프로그램 폴더에 덮어쓰지 마세요. PC를 바꾸려면 프로그램을 종료한 뒤 폴더 전체를 복사하거나 관리자 설정의 DB 백업을 사용하세요. 다른 프로그램의 DB는 열지 않습니다. 실행 중인 장부를 USB 드라이브에서 분리하거나 네트워크·동기화 드라이브에서 동시에 열지 마세요. 한 PC·한 매장 단독 운영이 대상입니다.

화면·PDF·라벨의 한글 표시를 위해 OFL 라이선스의 Noto Sans KR 글꼴을 함께 제공합니다. Windows 언어팩이나 온라인 글꼴 다운로드가 필요하지 않습니다. ZIP의 내부 파일도 함께 압축 해제해야 합니다.

`체험 실행.bat`이 있는 배포본에서는 별도 체험 자료로 화면과 기능을 확인할 수 있습니다. 체험 계정은 `demo` / `Standalone-Demo-2026!`이며 실자료 로그인에 사용할 수 없습니다. 체험 실행은 실제 장부와 다른 파일을 사용합니다.

## 업무 순서

- 공급사를 등록하고 상품장에 상품을 만듭니다. 기본단위(예: kg), 매입가·판매가, 원산지, 바코드, 재고 관리 여부를 정합니다. 금액은 원 단위 정수, 수량은 소수 셋째 자리까지 지원합니다.
- `매입 등록`에서 공급사를 선택하고 바코드 스캔 또는 상품 선택으로 행을 추가합니다. 초안은 재고·원장에 반영하지 않습니다. `확정`하면 거래·재고·결제가 함께 저장됩니다.
- 판매 등록에서도 같은 방법으로 상품을 추가합니다. 비회원 외상은 판매처 원장에서 추가 결제합니다. 회원 매출은 현금/계좌이체+포인트로 완전 정산해야 합니다.
- 확정 거래는 직접 금액을 덮어쓰지 않습니다. 가능한 경우 사유를 넣어 취소하고 다시 등록하거나, 원전표·원행에 연결된 부분 반품을 등록합니다. 취소는 후속 재고·반품·포인트·마감 조건에 따라 제한됩니다.
- 실사는 장부수량을 조회해 초안 저장 후 적용합니다. 초안 이후 재고·원가·이동 이력이 달라지면 적용이 차단되므로 다시 조회해야 합니다.
- 일·월·상품·분류·공급사·회원 보고서, 거래처 원장, 사용자별 현금 마감, 월 재고 마감을 사용할 수 있습니다. 월 마감 이후 해당 기간 거래·재고 변경은 차단됩니다.

## 사진을 참고한 화면

상단 업무 메뉴·바로가기, 왼쪽 업무 트리, 넓은 조회표, 날짜·공급사·상품 필터를 배치했습니다. 상품 등록은 상품정보·매입·판매·재고·변경기록·확장단위 탭으로 구성합니다. 원본 프로그램의 로고·아이콘·이미지는 사용하지 않고 밝은 색의 새 UI로 설계했습니다. 표는 정렬·열 너비 변경과 천 단위 금액 표시를 지원합니다.

## USB 바코드 리더기

키보드처럼 입력되는 **USB HID 방식**을 지원합니다. 리더기의 종료 문자를 Enter 또는 Tab으로 설정하고 F8 또는 바코드 입력칸을 선택한 뒤 스캔하세요. 바코드는 문자열로 처리해 앞자리 0을 보존합니다. 스캔 완료만으로 저장·확정되지 않습니다. 기본 바코드와 확장단위(예: kg 상품의 500g 팩) 바코드를 구분하고 같은 기본 재고로 환산합니다. 미등록 바코드는 안내하며 임의 상품을 자동 생성하지 않습니다. 전용 시리얼·네트워크 장치 프로토콜은 포함하지 않습니다.

## 인쇄·라벨·엑셀

- 조회표와 거래 내역은 `인쇄`에서 미리보기 후 Windows에 설치된 프린터로 출력합니다. PDF 프린터도 사용할 수 있습니다. 엑셀은 `.xlsx`로 저장하며 금액·수량을 숫자로 내보냅니다.
- 상품장에서 상품을 선택하거나 `라벨 출력` 메뉴를 열어 상품·확장단위의 바코드 라벨을 만듭니다. 상품명·가격·원산지·바코드가 출력됩니다.
- 라벨 기본 크기는 **60×40mm**입니다. 가로 30~150mm, 세로 20~150mm, 위치 보정·매수를 지정할 수 있습니다. 프린터 드라이버에도 실제 용지와 같은 사용자 지정 크기를 설정하세요. 크기가 다른 상태로 인쇄하면 차단됩니다.
- Code128 또는 유효한 EAN13을 사용합니다. 잘못된 EAN 체크 숫자는 임의 수정하지 않습니다. 앞자리 0을 보존해야 하는 코드는 자동 모드에서 Code128로 출력합니다. 용지에 비해 너무 긴 바코드는 출력하지 않습니다.
- 프린터 모델을 정하면 제조사 Windows 드라이버를 설치하세요. 실제 기기에서는 먼저 **라벨 1장**으로 크기·위치·스캔 여부를 시험해야 합니다. 클라우드에서는 물리 프린터와 리더기의 동작을 직접 확인할 수 없습니다.

## 자료 보호와 주의

계정별 접근 권한과 관리자 전용 설정을 분리하고, 비밀번호는 개별 salt가 있는 scrypt 해시로 저장합니다. 현재 로그인 계정 삭제·마지막 활성 관리자 제거를 차단합니다. 단, SQLite 파일 전체는 암호화하지 않으므로 Windows 계정·디스크 접근 권한과 정기 백업이 필요합니다. 계정 비밀번호를 잊었을 때 사용할 백도어는 없습니다.

재고원가는 **등록순 이동평균**입니다. 과거 날짜로 거래를 입력해도 이후 원가를 자동 재계산하지 않습니다. 보고서 분류는 현재 상품 분류 기준이며 거래 금액·상품명·수수료율 등은 저장 시점 기준입니다. 서로 다른 단위의 수량을 합산하지 않습니다. 공급사 수수료 보고서는 로컬 정산 자료이며 은행 송금·전자 세금 신고가 아닙니다. 이 프로그램의 보고서가 세무 신고의 정확성을 보증하지는 않습니다.

카드 승인/VAN·현금영수증 승인·센터 연결·온라인 상품 수신·SMS·원격지원·자동업데이트는 포함하지 않습니다. 종이 매뉴얼의 모든 기능을 완전히 복제한 제품은 아니며, 기능 대응과 미구현 범위는 `MANUAL_ANALYSIS.md`를 확인하세요.

## 소스 실행·검증

이 디렉터리는 기존 프로그램과 분리된 프로젝트입니다.

```bash
cd standalone
uv sync --frozen --extra dev
uv run --frozen --extra dev pytest -q
QT_QPA_PLATFORM=offscreen uv run --frozen --extra dev python -m pos2 --smoke-test
uv run --frozen python -m pos2
```

Windows PowerShell에서는 `$env:QT_QPA_PLATFORM = 'windows'`로 실제 Windows Qt 플랫폼을 사용해 검증합니다. Linux 클라우드 검증에는 `offscreen`을 사용합니다. Windows에서 `python build_portable.py`로 네이티브 EXE를 만듭니다. Linux 빌드는 Windows 실행 파일로 제공하지 않습니다.
