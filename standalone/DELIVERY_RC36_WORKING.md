# SY POS rc36 소스 작업본 전달 안내

이 ZIP은 변경된 파일을 포함한 전체 개발 소스 스냅샷입니다.
Windows 무설치 실행파일이나 PDF 전체 기능 구현 완료판이 아닙니다.
최신 Windows 공개 검증본 rc35와 혼동하지 마세요.

## 진행률

첨부 설명서를 반영하는 현재 월마감·결제 개선 단계는 **60% (3/5)**입니다.

1. 완료: 원본 규칙 분석.
2. 완료: 장부 기능 구현.
3. 완료: 결제창 연결 및 관련 검사.
4. 진행 중: 중복 버튼·하위 메뉴 동작 점검.
5. 미완료: 최신 소스 전체 회귀 및 Windows 실행파일 검증.

이 수치는 PDF 전체 기능이나 프로젝트 전체의 완성률이 아닙니다.

## 포함된 주요 변경

- 매입 4열 클립보드 검토 입력, 달력 범위와 저장 전표 월 고정.
- 입력(F5) → 확정(F9) 일괄결제, 여러 지급·할인 수단, 거래원장 결제확인 O.
- MIS 월마감 이력·이월 스냅샷, 마감 이전 변경 차단.
- 미마감 과거 결제 묶음 정정·취소와 원기록 보존.
- 기존 rc36의 한글 우클릭, 붉은 반품, F11 가격 추이, 행/셀 선택 변경도 포함.

## 사용 전 주의

- 장부 형식은 218입니다. 기존 자료 사본과 보호 백업을 사용하세요.
  변환한 자료는 rc35에서 열 수 없습니다. 실제 매장 자료로 바로 시험하지 마세요.
- 같은 어음번호를 유지하는 결제 정정은 아직 미완료이며 중복 번호 검사로 차단됩니다.
- 펼쳐보기의 상세 금액 열·보증금 계산, 전표 분리/합치기 등 미완료 기능이 있습니다.
- 결제창을 띄워 다른 업무창과 편리하게 오가는 구조와 중복 버튼 점검도 진행 중입니다.
- 은행 송금·카드 승인 자동 실행이 아닌 수기 장부 기록입니다.
- 실제 매장 DB·개인 기록·첨부 원본 PDF·인증정보는 이 ZIP에 포함하지 않습니다.
