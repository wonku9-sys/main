# SY POS 독립판 2.4.0rc13 · 첨부 MP3 6개 자동 적용

- 사용자가 공개 배포를 승인한 MP3 원본 6개를 기본음으로 포함했습니다. 로그인 성공·경고/알림·왼쪽 클릭·오른쪽 메뉴 열기·행운의 숫자 열기·공 추첨 결과에 각각 자동 연결합니다. 새 PC에서 파일을 하나씩 지정할 필요가 없습니다.
- 기존 사용자 선택 파일과 켜기/끄기·음량·전체 효과음 설정은 유지합니다. 이전 PC의 파일 경로가 없으면 동봉된 기본음을 사용하며, ‘기본음으로 복원’은 사용자 원본을 지우거나 꺼 둔 소리를 켜지 않습니다.
- 사운드 설정에서 여섯 종류를 함께 조회·미리 듣기·설정하고 장치 없음·파일 누락·재생 오류를 확인합니다. 로그인 실패에는 성공음을 재생하지 않고, 우클릭은 실제 메뉴가 열릴 때만 소리를 냅니다.
- 빌드에서 기본음의 원본 SHA256을 검사하며, 실제 Windows EXE에서도 6개 MP3를 PCM으로 디코딩합니다. 자동 검사는 실제 스피커 청취나 사용자 PC 음량을 보장하지 않습니다.
- MP3는 승인된 위치·파일명·해시의 6개만 배포합니다. 사용자별 음원·설정, 상품 원본 목록·개인 자료·ROM은 포함하지 않습니다. 기존 장부·암호 형식은 변경하지 않았습니다.
- 중간 rc12는 Windows 검사에서 같은 경로의 슬래시 표기 차이를 실패로 판단해 ZIP을 게시하지 않았습니다. 파일 경로 객체로 정확히 비교하도록 수정해 rc13으로 구분합니다.

## 이전 2.4.0rc11 · 상품장·과면세·분류·변경로그·하단 바로가기

- 상품 목록 XLS/XLSX 등록 미리보기·검색·과면세 직접 지정·추천 분류·500개 페이지를 추가했습니다. 원본 BIFF2 상품 35,190개를 분석하며 통계 행은 제외합니다. 과면세/분류가 없는 원본은 확정값으로 가장하지 않고 추천/확인 필요로 구분합니다.
- 등록은 보호 백업 후 새 상품만 일괄 생성하고 중복은 건너뜁니다. 기존 가격·재고·거래는 변경하지 않고 실패하면 전체 취소합니다. 실제 업로드 목록은 공개 저장소/ZIP에 포함하지 않습니다.
- 초록 ‘면’ / 붉은 ‘과’ 배지와 문자, 상품장 오른쪽 분류 트리, 검색 순번/개수, 수정 가능한 기본 분류 구성을 추가했습니다.
- 상품 독립 창에 상품정보·매입정보·판매정보·재고정보·변경로그·회원지정가·확장단위를 제공합니다. 변경로그는 변경전·후·차액·비율·일시·사용자와 필터·엑셀·인쇄를 지원합니다.
- ‘나의 기록’은 작업영역 가운데 하단 아이콘 바로가기로 이동했습니다. 왼쪽 메뉴 공간을 확보하고 글자가 잘리지 않도록 최소 버튼 폭을 확보했습니다.
- Windows에서 즉시 우클릭/메뉴 열림의 단조시계 값이 같아 소리를 누락하던 경계를 수정했습니다.

## 점포·문서·마이너스 재고·게임·복구·사운드 통합

- 기초관리 ‘점포 등록정보’에 사업자·대표자·업태·종목·연락처·은행·계좌를 추가하고 새 문서 공급자에 자동 입력합니다. 기존 문서는 작성 당시 점포 정보를 보존합니다.
- 견적서·거래명세서·주문서에 원본 A4 공급자/공급받는 자·품목·과면세·합계·입금 계좌·확인란 양식을 제공합니다. 인쇄 미리보기/프린터, PDF, PNG와 이미지 이메일 첨부 전송을 사용합니다. 실제 메일은 관리자 SMTP 설정·인터넷·명시적인 수신 주소 확인이 필요합니다. 거래명세서는 확정된 원판매전표 기반이며 법정 전자세금계산서는 아닙니다.
- 주문서에 주문일/배달일·상태 조회, 전화/방문/인터넷 수동 접수, 배달 담당·연락처·주소·설명, 접수/인쇄/완료/취소를 제공합니다. 저장만으로 재고·매출을 변경하지 않고, ‘판매 등록’에서만 실제 거래를 생성합니다. 여러 PC가 같은 주문을 처리해도 한 판매로 연결하고 문서 편집 충돌을 차단합니다. CID·인터넷 주문 자동 수신·카드 승인 장치는 미지원입니다.
- 재고 부족 거래를 기본 허용하고 음수를 빨간색으로 표시합니다. 환경설정에서 차단 방식으로 바꿀 수도 있습니다. 부족분 원가·이익은 잠정값으로 표시하고 과거 금액을 몰래 재작성하지 않습니다. 입고 확인 후 실사로 원가 차이를 조정하며, 수량 0에 원가가 남은 월말은 실사 후 마감합니다. 폐기·사은품·포인트의 기존 부족 제한은 유지합니다.
- 행운의 숫자 ‘미니 오락실’에 자체 블록 퍼즐(테트리스 방식)·자유 오목·우주 슈팅·점프 어드벤처·버블 아케이드·너구리(과일 사다리)를 제공합니다. 독립 팝업·일시정지·다시 시작·최근 기록·최고점수를 지원합니다. 너구리는 사다리·점프·과일 수집·적·시간 제한·3목숨·5스테이지가 있는 자체 게임입니다. 원작 캐릭터·음악·ROM은 자체 게임에 사용하지 않습니다.
- ‘내 게임’에서 승인된 슈퍼 마리오 1·2·3 / 버블보블 1·2 / 슈퍼 마리오 올스타 + 월드의 보유 NES/SNES/ZIP을 로컬 등록하고 직접 선택한 호환 EXE(FCEUX/Snes9x/MAME 등)로 실행합니다. 공개 ZIP에는 ROM·실행기를 포함하지 않습니다. 실제 에뮬레이션·ROM 세트/BIOS 호환은 사용자 PC에서 확인해야 합니다. 외부 게임 점수는 자동 추출하지 않으며 실행기 저장 기능 또는 수동 점수 기록을 이용합니다.
- 행운의 숫자 메뉴 열기/공 추첨의 MP3·WAV를 각각 선택·미리 듣기·켜기/끄기·음량 조절하고 다음 실행에도 기억합니다. 번호 결과 표시 시 한 번만 재생하며 추첨 시작/닫기 때 필요한 소리를 멈춥니다. rc11까지는 기본 MP3를 포함하지 않았으며 이번 수정에 승인된 6개를 자동 적용했습니다.
- 로그인 성공음과 메시지 경고음도 별도 파일·음량·켜기/끄기로 설정합니다. 암호 실패는 성공음을 재생하지 않으며 경고/오류·일정 알림은 경고음을 사용합니다. 로그인 전·독립 팝업의 기본 열기/닫기·경고음을 연결하고 환경설정에서 제어합니다.
- 왼쪽 클릭·오른쪽 메뉴 열기 MP3도 각각 선택하고 환경설정에서 개별 켜기/끄기·음량을 조절합니다. 우클릭 요청 뒤 실제 메뉴가 열린 경우에만 메뉴 소리를 재생하고, 마우스 이동/키 입력에는 재생하지 않습니다. 사용자가 별도로 선택한 음원은 이 PC에만 보관합니다.
- Windows에서 미저장 작업을 약 2초 간격으로 암호화 보관하고 다음 로그인 때 복구 창을 제공합니다. 주요 상품·공급사·전표·문서·실사·설정·업무·개인 기록 입력창으로 복귀하며 보조 입력창은 임시 내용을 확인해 직접 옮깁니다. 복구만으로 거래를 확정하지 않으며 개인 기록은 추가 자료키가 필요합니다. 마지막 약 2초·이미 멈춘 뒤의 입력·저장장치 장애까지 완전 복구를 보장하지 않습니다.
- ‘나의 기록’ 메뉴 이름 잘림을 수정했습니다. 상단 금색 고정 조회(F5), 모서리/테두리 크기 조절·손잡이·스크롤·전체화면을 포함합니다. Windows CI의 화면 범위를 벗어난 테스트 요청은 화면 안의 여러 크기로 변경해 실제 확대·축소·내용 접근 검사를 유지했습니다. rc8은 해당 검사 실패로 Windows 파일을 게시하지 않았으며 이 버전에 통합합니다.

기존 자료를 별도로 백업하고 새 폴더에 전체 압축을 풀어 실행하세요. 장부 구조 212로 처음 변경하기 전에 자동 보호 백업도 남깁니다. 구버전 EXE로 새 장부를 열지 말고 PC 공유 시 전부 같은 버전으로 맞추세요. 게임·개인 임시본 폴더는 매장 DB 백업과 별도입니다. NAS·코드서명은 미구현입니다.

## 이전 2.4.0rc6 변경 이력

## 실행

`SeoyoungPOS-Standalone-v2.2.0-Windows-x64-portable.zip`을 모두 압축 해제한 후 `SeoyoungPOS-Standalone.exe`를 실행합니다. Windows 10/11 x64에서 Python 설치, 서버, 인터넷, 카드 연동 없이 사용합니다. 새 장부는 admin / 1234로 로그인한 후 비밀번호를 변경합니다. 업무 자료는 실행 파일 옆 `data-v2` 폴더에 저장되므로 프로그램을 옮길 때 이 폴더도 함께 보존합니다.

동봉한 `체험 실행.bat`은 별도의 체험 DB로 실행합니다. 체험 자료는 실제 업무 자료와 섞이지 않습니다. 독립 소스 ZIP에는 새 프로젝트의 `pyproject.toml`, `uv.lock`, 클라우드 준비 스크립트와 원본 의존성 라이선스도 포함합니다.
