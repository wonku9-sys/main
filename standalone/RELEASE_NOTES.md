# 서영 POS 독립판 2.3.0rc1 · 화면 확인용 미리보기

새 폴더에 전체 압축을 풀고 `체험 실행.bat`으로 먼저 확인하세요. 실자료의 초기 로그인은 admin / 1234이며 최초 로그인 화면에서 본인 암호를 반드시 설정합니다. 실제 자료를 사용하기 전 백업하세요. 새 장부 형식은 구버전 EXE로 다시 열 수 없습니다.

- 첫화면 달력·PC 시각·계정별 일정/메모/알림, 매입/발주관리만 펼친 초기 메뉴
- 기초·판매·레포트·회원 하위 메뉴, 공급사 관리/그룹, 3단계 분류와 기본 미분류/미분류/신상품
- g·100g 단가, 단가/전표/결제/잔액 0.01원 보존과 선택적 원 단위 반올림
- 매입전표에서 별도 상품장 등록 후 즉시 품목 적용, 상품·확장단위 우클릭과 상품변경로그
- 실제 재고·결제에 재반영하지 않는 견적서·거래명세서·회원 계산서 참고자료와 출력
- 업무 메뉴와 분리한 나의 기록: 암호화 일기장, 별도 암호 선택 가계부, 업무일지
- 고급스러운 초록·크림 로그인 디자인과 매장/가계부/일기장 아이콘 바로가기, 테마 5종과 끌 수 있는 팝업 효과음
- 가계부 달력·날짜별 자유 메모, 양력/한국 음력 기념일·생일·제사 반복 알림, 경과 일수·나이/주년 및 강조 알림 팝업
- 개인 창의 건강·병원 기록: 아이 이름별 키·몸무게·성장 나이·메모, 식사·운동·진료·예약·약국 금액 (가계부·매장 장부에 자동 합산하지 않음)
- 이메일 전용 암호 복구: SMTP 설정 후 최초 주소 인증, 만료/오입력/재요청 제한. 일기장·가계부는 사전 등록 메일의 복구키와 새 인증번호가 모두 필요합니다.
- 일기장에 오프라인 자체 생성 음악: 계절·날짜 1~31 변주, 낮은 기본 음량, 끄기·음량 조절, 잠금 시 정지
- 날씨·인터넷 시각은 선택 기능이며 기본 꺼짐입니다. 지역은 직접 지정하고 GPS/IP 위치 조회는 하지 않습니다.

이메일 실발송은 사용자의 SMTP 계정·인터넷·수신함에서 확인해야 합니다. 실제 프린터/스캐너/스피커는 매장 PC에서 확인하세요. 유명 클래식 녹음, 복사 추적, 관리자 자동 메일 통보, 원격 정지는 아직 포함하지 않았습니다. 계산서는 세무 신고·전자 발급용 법정 서식이 아닙니다. 미구현·제외 항목과 복구키 보관 주의는 동봉 README를 확인하세요.

Windows 테스트와 새 동결 EXE 스모크를 통과해야만 게시됩니다. 업무 DB·개인 자료·SMTP 비밀번호는 배포 파일에 포함하지 않습니다.

## 아래는 2.2.0 변경 이력 (구버전 실행파일 안내)

PDF의 매장 업무를 기준으로 별도 설계한 신규 오프라인 Windows 프로그램입니다. 기존 서영 POS의 소스·화면·DB를 가져오거나 갱신하는 버전이 아닙니다.

## 이번 변경

- PDF p.12~19의 이름과 순서에 맞춰 **매입/발주관리 → 매입전표 → 매입등록**, 같은 창의 **반품** 체크, 전체/매입/반품 조회 필터를 적용했습니다. 전표 적용은 초안 저장 후 계속 작업, 저장은 확인 후 확정입니다. 반품은 원전표 연결과 남은 수량 검증을 유지합니다.
- 모든 메뉴·편집창의 첫화면 이동과 작업 저장/저장하지 않음/돌아가기 확인을 추가했습니다. 첫화면으로 이동할 때 전표·실사는 초안으로 저장합니다.
- 메뉴에 약 0.7초 커서를 머무르면 간단한 한글 설명을 보여줍니다.
- 자동/수동 백업 설정, 매일·선택 요일·며칠 간격과 실행 시간, 종료 시 자동 백업을 추가했습니다. 프로그램이 꺼진 시간의 일정은 다음 실행 때 한 번 백업하며, 종료 백업은 기본 켜짐입니다. 강제 종료·정전에는 실행되지 않습니다.
- PDF p.142~145를 참고해 관리자 전용 **권한 설정** 메뉴를 추가했습니다. 직원별로 메뉴 접근·등록·수정/편집·삭제/취소를 나누고 실제 저장 처리에서 최신 권한을 검사합니다. 읽기 전용 직원과 기존 권한의 호환을 지원합니다.
- 압축파일 이름에 버전을 표기합니다. 이번 파일은 `SeoyoungPOS-Standalone-v2.2.0-Windows-x64-portable.zip`입니다.

- 매입장 기간·전체/선택 공급사 조회, 돋보기 검색 → 공급사 선택 → 매입전표 팝업 흐름을 정리했습니다.
- PDF p.146~153을 참고한 **결제관리**를 별도 메뉴로 추가했습니다. 공급사 외상 현황·거래/전표 상세·전체/선택 결제 이력·부분 지급·초기 외상/전표 순차 배분·당일 취소와 인쇄/엑셀을 연결했습니다. 실제 송금·카드 승인은 하지 않습니다.
- 상품검색은 선택 공급사부터 표시합니다. 체크를 해제하면 전체 공급사 품목을 보고, 여러 품목을 체크해 적용할 수 있습니다. 상품코드·바코드·상품명·규격 검색을 지원합니다.
- 매입전표에 규격·바코드·환산량·총수량·단가·금액·분류·공급사를 배치하고, **미지급잔액·결제상태**를 표시합니다. 초안 예상과 확정 전표의 실제 잔액을 구분합니다. 참고 판매가·예상이익은 확정 매출 이익이 아닙니다.
- 상품코드를 중복 없이 순차 생성합니다. 상품 상태는 유효·무효·퇴출대상으로 나누었습니다.
- 새 장부의 초기 로그인은 요청하신 **admin / 1234**이며 로그인 하단에 안내합니다. 관리자 모드·설정 바로가기를 제공하고 DB에는 개별 salt가 있는 scrypt 해시로 저장합니다. 공개 초기 비밀번호는 로그인 후 변경하세요. 기존 계정·비밀번호는 덮어쓰지 않습니다.
- 기초관리 상품 분류에 대·중·소분류 트리와 오른쪽 버튼 추가·수정·삭제 메뉴를 넣었습니다. 상품 등록에서는 먼저 만든 분류를 선택·검색합니다.
- 백업 폴더 자동 생성, 최신순 목록, 파일 선택 복원, 짧은 주의창, 비밀번호 재확인과 복원 전 보호 백업을 추가했습니다. **복원은 현재 자료 전체를 교체하고 프로그램을 종료합니다.** 다시 실행해 백업 속 계정으로 로그인하세요.
- 7일마다 오래된 자동 관리 백업을 정리하되 **최근 15개는 유지**하며, 삭제 후 알림창을 표시합니다. 장기 보관 파일은 별도 폴더에 복사하세요.

기존 독립판 2.0.0~2.1.0 백업을 선택 복원할 수 있습니다. 새 버전에서 연 DB는 구버전으로 다시 열지 마세요. 종전 폴더를 보존하고 새 폴더에서 실행·복원하는 방법을 권장합니다. Windows 한글 글꼴·인쇄·엑셀·USB HID 지원은 유지합니다.

## 실행

`SeoyoungPOS-Standalone-v2.2.0-Windows-x64-portable.zip`을 모두 압축 해제한 후 `SeoyoungPOS-Standalone.exe`를 실행합니다. Windows 10/11 x64에서 Python 설치, 서버, 인터넷, 카드 연동 없이 사용합니다. 새 장부는 admin / 1234로 로그인한 후 비밀번호를 변경합니다. 업무 자료는 실행 파일 옆 `data-v2` 폴더에 저장되므로 프로그램을 옮길 때 이 폴더도 함께 보존합니다.

동봉한 `체험 실행.bat`은 별도의 체험 DB로 실행합니다. 체험 자료는 실제 업무 자료와 섞이지 않습니다. 독립 소스 ZIP에는 새 프로젝트의 `pyproject.toml`, `uv.lock`, 클라우드 준비 스크립트와 원본 의존성 라이선스도 포함합니다.

## 포함 업무

- 상품장, 분류, 공급사·판매처, 단위별 별도 바코드와 정확한 확장단위 환산
- 매입·매출 초안 및 확정, 원전표에 연결한 부분 반품, 지급·수금, 거래처 원장
- 이동평균 재고원가, 재고 실사, 월 재고마감, 사용자별 현금마감, 기간별 분석
- 회원, 포인트 원장, 사은품, 기간 특매, 회원지정가, 예약가격
- 관리자·직원별 권한, 안전한 비밀번호 해시, 감사기록, SQLite 무결성 확인 백업
- Excel 내보내기, USB HID 키보드형 바코드 스캐너, 일반 Windows 프린터와 상품 라벨

카드·VAN·온라인 승인, 센터·점포 서버 동기화, SMS, 인터넷 상품정보, 원격지원, 자동업데이트와 전용 단말·저울 프로토콜은 포함하지 않습니다. 프린터와 스캐너는 실제 매장의 장치·용지 설정에 맞춰 확인해야 합니다. 세부 구현 범위와 사용법은 동봉한 새 독립판 README를 확인하세요.

확정 전표는 감사 가능한 기록 보존을 위해 직접 수정·삭제하지 않고 취소·재등록합니다. 반품은 원전표의 수량·단가를 초과할 수 없습니다. 포인트 지급과 사용은 완전 정산된 회원 매출에 적용하며, 확장단위 가격은 기본단위 행사 가격을 임의 환산하지 않습니다.

## 배포 검증

이 Windows 릴리스는 Windows 2022 환경의 독립판 테스트, 새로 동결한 EXE의 격리된 데모 스모크 테스트, ZIP CRC와 SHA256 검증 이후에만 자동 게시됩니다. 테스트 자료와 기존 프로그램·업무 DB는 배포 ZIP에 포함하지 않습니다.
