# SY POS v2.4.0rc34 · 세로형 상품등록 · 저장/취소/적용

- PDF 22쪽 상품등록 설명·그림17 및 최신 사용자 캡처를 대조하여 상품창을 700×800 세로형으로 정리합니다. 기존 SY 색상과 3D 아이콘, 상세 이력·회원가격·확장단위 탭은 유지합니다. 작은 화면에서는 본문만 스크롤하고 하단 작업은 고정합니다.
- 하단은 저장(S) → 취소 → 적용(A) 세 개만 둡니다. 중복 첫화면·저장 후 다음 상품·닫기 버튼은 제거합니다. 저장은 등록 후 닫기, 취소는 현재 입력을 저장하지 않고 닫기, 적용은 등록 후 창을 유지하며 상품명·바코드·코드·단가·보관정보·메모를 초기화합니다. 분류·공급사만 연속 입력을 위해 유지합니다.
- 적용 후 내부 상품 ID와 편집 토큰도 비워 다음 저장이 이전 상품을 덮어쓰지 않도록 합니다. 입력 오류·중복 바코드·권한 실패 시에는 입력을 지우지 않습니다. 매입전표에서 등록한 각 상품은 전표에 한 번씩 전달하며 상품등록만으로 전표·재고를 확정하지 않습니다.
- 대▸/중▸/소▸ 화살표에서 실제 분류를 선택합니다. 상위 분류에 속한 유효 분류만 보여주고 선택 직전 다시 검증합니다. 분류(C) 전체 경로 검색도 유지합니다. 상위 변경 시 이전 하위 경로는 남기지 않습니다.
- Alt+S 저장, Alt+A 적용, Alt+C 분류, Alt+V 공급사 검색을 제공하고 버튼에 설명을 표시합니다. 상품 단가·최소재고에도 세 자리 쉼표를 표시하며 실제 저장값과 바코드는 바꾸지 않습니다.
- 행운의 숫자 상단의 불필요한 조회(F5) 버튼을 숨기고 비활성화합니다. 순차 공 추첨과 사운드·복사는 유지합니다.
- 공통 상단은 이전/다음 | 첫화면/달력 | 상품장/매입전표/판매조회 | F8 스캔의 네 구획으로 정돈하고 아이콘 아래 이름을 유지합니다. 중복 조회·출력은 공통 도구막대에 추가하지 않습니다. SY POS 로고는 계속 F8 오른쪽 공간의 가운데에 놓입니다.
- 상품장·공급사관리의 필터를 사각 패널로 모으고 표를 넓게 씁니다. 상품장은 상품명/규격/바코드/공급사/매입가/판매가를 먼저, 공급사관리는 코드/공급사명/유형/사업자번호/담당자/전화 순으로 보여줍니다. 논리 열·상품 ID·정렬/저장값은 유지합니다. 분류 트리는 ‘추가 기능’에서 열며 수정·삭제·라벨·엑셀 등록은 같은 메뉴에 유지합니다. 단일 상단 조회와 우측 출력 아이콘은 유지합니다.
- 상품장·공급사 표의 실제 셀은 흰색, 이름 열은 연한 색, 빈 공간만 회색으로 그립니다. Qt 스타일이 셀 배경까지 덮는 문제를 고치고 실제 화면 픽셀을 검사합니다. 음수·과면세 색과 아이콘·정렬·선택은 Qt의 기존 그리기를 유지합니다.
- PDF 72~74쪽의 공급사 목록→추가/더블클릭→사업자/연락처/결제/계좌 입력→저장 흐름을 대조하고 공급사 등록창의 간격·구획을 정돈합니다. 일반 편집 팝업에 자동 추가하던 중복 첫화면 버튼은 제거합니다. 공통 등록폼의 저장/취소는 하단에 고정하고 내용만 스크롤합니다. 우측 X와 미저장 확인은 유지합니다.
- 공급사 ‘줄여보기’ 행 높이는 Windows 글꼴·스타일의 실제 최소 높이를 지킵니다. 25px을 강제하지 않고 글자가 잘리지 않는 최소 행을 사용합니다. 14/18/22px 글꼴에서도 확인합니다.
- 자료를 행 단위로 입력하는 표에는 같은 연속 셀 디자인을 적용합니다. 판매전표·견적서·주문서, 특매 가격, 재고실사, 매입 일괄입력, 업무일지의 작업량/작업인원, 고객 이메일/연락처, 가계부 거래 나누기, 직원 권한 설정이 대상입니다. 32px 기본 행·회색 빈 영역·연한 열 제목·사각 편집 셀을 공통으로 사용합니다. 조회 전용 DataGrid·달력·일반 입력폼은 임의로 변경하지 않습니다.
- 장부 형식 217 그대로이며 기존 data-v2를 보존해야 합니다. 이 배포는 상품등록 단계의 개선이며 PDF 전체 메뉴·외부 연동의 완성을 뜻하지 않습니다.

## 이전 rc33 · 매입 상품검색창 연속 유지

- 매입전표의 상품검색은 기본적으로 열린 채 유지합니다. Space 즉시 추가와 체크 후 Enter 적용 모두 다음 상품을 계속 검색·추가할 수 있습니다.
- 사진으로 지정한 검색창 하단 7개 버튼(이전/다음 500개, 선택행 체크/해제, 모두 체크/해제, 확인)의 아이콘을 제거합니다. 다른 화면의 기존 3D 아이콘은 유지합니다.
- 매입 수량·입수량·단가·판매가·직접 금액·일괄입력 및 상세 결제 금액은 입력 중에도 세 자리마다 쉼표를 표시합니다. 소수점·끝자리 0·커서 위치·키보드 실행취소를 보존하며 계산할 때는 기존 정확한 금액/수량 검증을 사용합니다. 바코드·상품코드·메모·계좌번호에는 적용하지 않습니다.
- 적용 뒤 검색어·체크를 지우고 검색칸으로 이동합니다. Space 키를 누르고 있어 생기는 자동 반복 입력은 기존처럼 차단합니다.
- X/Esc로 닫기와 ‘적용 후 검색창 유지’의 명시적 해제는 가능합니다. 판매·견적·특매 및 콜백 없는 단일 선택창의 기존 동작은 변경하지 않습니다.
- 장부 형식은 217 그대로입니다. 저장·재고·결제 계산·상세창·기존 입력값은 변경하지 않습니다. PDF 전체 구현은 계속 단계별 작업 대상입니다.

## 이전 rc32 · 엑셀식 매입표와 상세 결제 연결

- 매입 입력표를 연속된 시트형 셀로 변경합니다. 칸마다 둥근 입력 테두리를 없애고 32px 행, 연한 제목색·총수량/매입금액 강조색, 회색 여백, 행 번호를 사용합니다. 기존 3D 아이콘과 F3/F5/F6/F7/F8/F9/F11·저장 단축키를 유지합니다.
- 공급사·매입일시·담당자 → 사업자번호·반품 → 상품검색/매입수정/선택행삭제/일괄입력 → 품목표 → 공급가/부가세/수량/결제/외상/매입합계 → 메모·저장 순서로 정리합니다. 보조 기능과 바코드 입력은 기능 메뉴에서 열며 Ctrl+B 스캐너 입력도 유지합니다.
- 새 전표·초안·확정 전표의 결제(P)를 같은 상세 양식으로 연결합니다. 결제대상액/결제율, D/C율·장려금·쿠폰/스폰·기타 할인, 계좌이체·카드 수기·현금·어음, 결제일시(시·분)·인출계좌·메모를 입력합니다. 지급액+할인=대상액을 검증합니다.
- 저장 전 결제는 입력 계획일 뿐 재고·장부를 바꾸지 않습니다. 초안·비정상 종료 복원에도 유지하며 전표 확정 시 품목·재고·할인·어음·결제 전부가 하나의 트랜잭션으로 반영됩니다. 중간 실패 시 전부 롤백합니다.
- 결제 이력 더블클릭/선택 수정도 상세창을 사용합니다. 당일 결제 묶음만 수정·삭제하며 원래 이력은 취소 표시로 남깁니다. 지급 완료 어음, 마감, 다른 PC의 잔액 변경은 재검사합니다. 어음을 재발행하는 수정에는 새 어음번호가 필요합니다.
- 결제창의 전표삭제는 선택한 **결제 묶음**만 취소합니다. 매입전표 자체·품목을 삭제하지 않습니다. 실송금·카드 승인·어음 자동출금은 하지 않습니다.
- 시트에서 Enter로 다음 편집 셀, 위/아래로 같은 열의 이전/다음 행을 이동합니다. 바코드 Enter는 상품 적용 동작을 유지하며 Enter가 저장 버튼을 오작동시키지 않도록 합니다. 행 이동 시 직접 금액·입수량·판매가·메모도 보존합니다.
- 장부 형식 217: 업데이트 전 보호 백업을 남깁니다. 구버전은 새 결제 계획을 무시하지 않고 더 최신 장부라는 안내로 차단합니다. 이전 백업은 복원·업그레이드할 수 있습니다.

## 범위 안내

아래 rc31의 남은 차이는 이번에도 남아 있습니다. PDF 176쪽 전체의 모든 메뉴·외부 연동을 동일하게 완성했다고 주장하지 않습니다. 특히 확정 매입의 3개월 직접 수정·0원 전표 유지, 별도 발주서/원본, 모든 판매조회 필터·고급 행사·전용 장비·외부 데이터 서비스는 별도 작업 대상입니다. 이번 배포는 상세 결제와 매입 시트의 검증된 개선본입니다.

## 이전 rc31 · 매입 입력 순서와 실제 편집 보완

- PDF 12~15쪽 직접입력 순서를 기반으로 매입등록 → 공급사 선택 → 새 매입전표 → F5 상품검색 → Space 즉시 추가(최신 사용자 요청, 또는 체크 후 Enter) → 수량·금액 입력 → 저장 확인 → 매입상품 체크로 연결합니다.
- 상품검색은 확인 후 닫힘이 기본입니다. 연속 검색을 선택하면 반복해서 체크·확인할 수 있습니다. 검색·선택만으로 재고/결제가 바뀌지 않습니다.
- 매입일시(달력/시분), 표시 담당자, 품목 메모를 저장하고 다시 열 수 있습니다. 저장 사용자의 감사기록은 별도로 유지합니다.
- 매입금액 직접 입력, 매입단가, 판매단가, 입수량을 편집합니다. 금액 직접 입력의 나눗셈 반올림 차이를 합계·재고원가·반품에 정확히 보존합니다. 바코드 칸 Enter로 상품·확장단위를 적용합니다.
- 단가가 다르면 매입상품 체크에서 상품장 매입가·판매가 변경을 각각 선택합니다. 기본은 모두 미선택이며 전표와 상품장 변경은 하나의 트랜잭션으로 저장합니다. 환산 기준이 다른 행이나 동일 상품에 서로 다른 단가가 있는 경우 상품장을 자동 변경하지 않습니다.
- 일반 팝업의 중복 닫기 버튼은 숨기고 우측 X/Esc/Ctrl+W를 사용합니다. 저장되지 않은 변경 확인과 인증/작업 중 닫기 보호를 유지합니다. 매입전표 하단 저장 기능은 고정합니다.
- 장부 형식 216: 업데이트 전에 보호 백업을 남기며 구형 백업·업무 초기화에 새 입력정보를 포함합니다.
- 비정상 종료 임시 작업 복원에도 매입일시·직접 입력 금액·입수량·판매단가·메모를 보존합니다.
- 화면용 동봉 글꼴은 정적 Regular 인스턴스로 정리합니다. Windows Qt에서 메모리 등록 글꼴이 PDF 도형으로 변환되는 문제는 문서에 설치된 맑은 고딕을 우선 사용해 해결합니다. 해당 글꼴이 없을 때는 동봉 한글 글꼴로 안전하게 출력합니다. 실제 Windows PDF에서 사업자정보 7개 항목의 글자 추출까지 검사합니다.
- 매장 사업자정보와 견적서·거래명세서·주문서 연결 개선도 포함합니다.

## 이번 버전의 범위와 남은 차이

이 버전은 PDF 전체 기능을 동일하게 완성한 최종판이 아닙니다. 기존 확정 전표는 계속 읽기 전용이며 취소/연결 반품 방식입니다. PDF의 3개월 내 직접 수정·0원 전표 유지, 별도 발주서/발주서 원본, 모든 판매조회 필터·분석 화면의 일치는 후속 구현 대상입니다. DT-970 전용 통신·실제 카드 승인·실제 은행 송금·온라인 세금계산서 발급·타점포 데이터 비교는 연동하지 않습니다. 임의로 성공한 것처럼 표시하지 않습니다.

## 이전 rc30 작업 · 매장 사업자정보와 문서 연결 (단독 실행본 미배포)

- 매장 기본정보에 상호(영수증용), 사업자등록번호, 대표자명, 업태, 업종, 전화번호, 주소를 사진과 같은 2열 사업자등록증형 양식으로 배치합니다.
- 점포 등록정보와 같은 저장 항목·공통 양식을 사용하고 기존 정보·계좌·팩스·이메일을 보존합니다.
- 견적서·거래명세서·주문서의 공급자 화면과 문서 엑셀에 누락되던 대표자명·업태·업종을 모두 표시합니다. 인쇄/PDF/PNG의 업종 표기도 맞춥니다.
- 새 문서에는 저장한 매장정보를 반영하며 기존 발행 문서는 작성 당시 정보를 보존합니다. 새 문서 저장 후 화면에도 실제 저장된 공급자 정보를 갱신합니다.
- 사업자 입력값은 화면에서 일반 글자로 표시하고 출력 HTML은 계속 이스케이프합니다.

- 백업 폴더 자동 생성, 최신순 목록, 파일 선택 복원, 짧은 주의창, 비밀번호 재확인과 복원 전 보호 백업을 추가했습니다. **복원은 현재 자료 전체를 교체하고 프로그램을 종료합니다.** 다시 실행해 백업 속 계정으로 로그인하세요.

## 실행

`SeoyoungPOS-Standalone-v2.2.0-Windows-x64-portable.zip`을 모두 압축 해제한 후 `SeoyoungPOS-Standalone.exe`를 실행합니다. Windows 10/11 x64에서 Python 설치, 서버, 인터넷, 카드 연동 없이 사용합니다. 새 장부는 admin / 1234로 로그인한 후 비밀번호를 변경합니다. 업무 자료는 실행 파일 옆 `data-v2` 폴더에 저장되므로 프로그램을 옮길 때 이 폴더도 함께 보존합니다.

동봉한 `체험 실행.bat`은 별도의 체험 DB로 실행합니다. 체험 자료는 실제 업무 자료와 섞이지 않습니다. 독립 소스 ZIP에는 새 프로젝트의 `pyproject.toml`, `uv.lock`, 클라우드 준비 스크립트와 원본 의존성 라이선스도 포함합니다.
