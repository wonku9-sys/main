# SY POS 독립판 2.4.0rc5 · 사진식 분류 검색·선명한 버튼·개별 공 움직임

- 새 상품 등록창의 ‘분류 검색’ 버튼 하나로 별도 검색창을 엽니다. 대·중·소 입력칸과 세 열 결과표를 함께 보여줍니다.
- F5는 대분류, F6는 중분류, F7은 소분류 검색칸으로 이동합니다. 이름 버튼과 입력칸을 마우스로 눌러도 즉시 입력할 수 있습니다.
- 결과 더블클릭 또는 ‘선택 적용’으로 세 분류를 함께 적용하며 상품 자체는 별도 저장합니다. 취소·결과 없음은 기존 분류를 유지합니다. 무효 분류와 무효 상위 분류 아래 항목은 선택할 수 없습니다.
- 상품 상단을 ‘과면세’로 바로잡고, 상태·과면세·대/중/소 이름과 표시값을 가까이 붙였습니다. 임의 입력으로 분류를 생성하지 않으며 기본 미분류/미분류/신상품을 유지합니다.
- 아래 2.4.0rc4 작업의 선명한 시작 버튼·독립 공 45개 움직임을 함께 포함합니다. 분류 추가 요청을 묶기 위해 rc4의 중간 배포 작업은 중단했습니다.

기존 자료를 먼저 백업하고 새 폴더에 전체 압축을 푼 뒤 실행하세요. NAS 연동·Windows 코드서명은 포함하지 않았습니다.

## 2.4.0rc4에 작업한 내용 (rc5에 통합)

- 로그인 응원 팝업의 ‘닫고 시작하기’가 흰 글자·밝은 배경으로 흐리게 보이던 문제를 고쳤습니다. 진한 초록 배경과 굵은 흰 글자를 사용하고 마우스 올림·클릭·초점·비활성 상태도 명확히 구분합니다.
- 응원 팝업 기본 크기를 늘렸으며, 비활성 강조 버튼은 읽을 수 있는 회색으로 구분합니다. 비활성 버튼의 실행 차단은 유지합니다.
- 마음에 드신 실물형 추첨기 이미지는 그대로 유지했습니다. 공 45개가 공기 흐름을 따라 섞이고, 서로 부딪히며 회전하고 벽에서 튕깁니다. 추첨 후에는 중력으로 가라앉습니다.
- 움직임은 프레임 수가 아닌 실제 경과 시간으로 계산합니다. 숨김·닫기 때 타이머를 멈추고 가라앉은 후에는 불필요한 갱신을 중지합니다.
- 한 개씩·6개 자동·5줄 채우기와 기존 빈 팝업·이중 창 수정은 유지합니다. 공 움직임은 화면 표시용이며 실제 번호는 기존의 독립적인 무작위 선택을 그대로 사용합니다.

개인 기록·암호·장부 형식은 변경하지 않았습니다. NAS 연동·Windows 코드서명은 이번 버전에 포함하지 않았습니다. 기존 폴더를 보관하고 새 폴더에 전체 압축을 풀어 시험하세요.

## 이전 2.4.0rc3 변경 이력

- 독립 메뉴 창이 테두리와 버튼만 보이고 내용이 비어 있던 문제를 수정했습니다. 업무일지·상품장·매입전표 등에서 내용 영역을 실제로 표시합니다.
- 일기장·가계부를 열 때 불필요한 안내창이 함께 뜨지 않습니다. 기존 창은 재사용하고, 닫았다 다시 열 때 같은 로그인 세션은 유지합니다.
- 일기장 기록창의 ‘일기장 설정’에서 암호·이메일 복구를 관리합니다. 잠금 해제 화면에서도 이메일 암호 찾기에 접근할 수 있으며 암호 변경을 취소해도 열린 일기장이 잠기지 않습니다.

- 오른쪽 참고 사진·사진 출처 링크를 없애고, 번호 6개씩 총 5줄 결과판으로 변경했습니다.
- 추첨기를 누르거나 ‘1개씩 뽑기’, ‘6개 한 번에 뽑기’, ‘5줄 자동 채우기’를 선택할 수 있습니다. 진행 중인 줄은 이어서 완성하며 이미 완성한 줄은 유지합니다.
- 새로 생성한 실물형 추첨기 이미지에 움직이는 입체 번호 공과 진행 표시를 합성합니다. 오른쪽 결과판에는 참고 사진이나 출처 링크를 표시하지 않습니다.
- 완성된 줄은 오름차순이며 한 줄 안에서는 번호가 겹치지 않습니다. ‘번호 복사’는 완성된 줄을 복사하고 ‘새 추첨’은 확인 후 초기화합니다.
- 로그인 전 독립 팝업과 오프라인 사용은 유지합니다. 재미용이며 당첨 예측·실제 구매와 무관합니다.

NAS 연동과 Windows 코드서명은 이번 수정에 포함하지 않았습니다. 새 폴더에서 먼저 체험하고, 자료를 옮길 때는 기존 프로그램을 종료한 후 data-v2 폴더를 함께 옮기세요. 배포 파일에는 사용자 자료가 없습니다.

이메일 실발송은 사용자의 SMTP 계정·인터넷·수신함에서 확인해야 합니다. 실제 프린터/스캐너/스피커는 매장 PC에서 확인하세요. 유명 클래식 녹음, 복사 추적, 관리자 자동 메일 통보, 원격 정지는 아직 포함하지 않았습니다. 계산서는 세무 신고·전자 발급용 법정 서식이 아닙니다. 미구현·제외 항목과 복구키 보관 주의는 동봉 README를 확인하세요.

Windows 테스트와 새 동결 EXE 스모크를 통과해야만 게시됩니다. 업무 DB·개인 자료·SMTP 비밀번호는 배포 파일에 포함하지 않습니다.

## 실행

`SeoyoungPOS-Standalone-v2.2.0-Windows-x64-portable.zip`을 모두 압축 해제한 후 `SeoyoungPOS-Standalone.exe`를 실행합니다. Windows 10/11 x64에서 Python 설치, 서버, 인터넷, 카드 연동 없이 사용합니다. 새 장부는 admin / 1234로 로그인한 후 비밀번호를 변경합니다. 업무 자료는 실행 파일 옆 `data-v2` 폴더에 저장되므로 프로그램을 옮길 때 이 폴더도 함께 보존합니다.

동봉한 `체험 실행.bat`은 별도의 체험 DB로 실행합니다. 체험 자료는 실제 업무 자료와 섞이지 않습니다. 독립 소스 ZIP에는 새 프로젝트의 `pyproject.toml`, `uv.lock`, 클라우드 준비 스크립트와 원본 의존성 라이선스도 포함합니다.

## 배포 검증

이 Windows 릴리스는 Windows 2022 환경의 독립판 테스트, 새로 동결한 EXE의 격리된 데모 스모크 테스트, ZIP CRC와 SHA256 검증 이후에만 자동 게시됩니다. 테스트 자료와 기존 프로그램·업무 DB는 배포 ZIP에 포함하지 않습니다.
